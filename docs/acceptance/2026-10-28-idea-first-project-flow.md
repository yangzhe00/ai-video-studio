## 测试环境与证据规则

隔离 API 使用本轮专属临时数据目录、账号 A/B、受控 OpenAI-compatible Chat Completions 模拟端点；模拟端点记录请求数、输入摘要、返回与故障注入，草案请求 ID 从 API／数据库核对。视频生成供应商也使用模拟响应，默认不触发真实付费生成。网页指向该 API；桌面明确核对 `AI_VIDEO_API_BASE_URL` 指向同一实例，账号隔离分别验证。测试数据不复用用户已有项目或生产密钥。

真实模型联调须另记模型地址、模型名、配置方式与调用结果，**不记录密钥值**；模拟测试通过不能替代真实模型验收。截图必须来自实际浏览器页面或真实 Tauri 窗口，标注时间、客户端及模拟／真实服务状态；不以构建成功或 HTML 原型截图替代。若无法启动原生窗口，保留启动日志和明确阻塞项。

1. 后端契约完成后运行其聚焦测试、完整 API 测试和数据库迁移测试；前端集成后运行网页、桌面与共享组件测试、`pnpm test`、`pnpm build`、必要的 Rust 检查及 `git diff --check`。对并行编辑中的不稳定快照标明时间并重跑，不把旧日志当本次结果。
2. 真机浏览器和桌面验收按上表保存日志与截图，再独立审查本轮差异：账号权限、模型凭证、同 ID 重放、超时重试、三版只对应一个镜头、无静默建项目或视频提交、项目库状态、桌面状态文案、可访问性，以及是否误改桌面同步协议。

## 2026-10-29 只读审查与隔离环境准备

- 当前新增的 `apps/api/src/prompt-ideas.ts` 在模型 HTTP 请求前持久化 `pending`，同 ID 并发重放和账号隔离已有聚焦测试。`apps/api/src/idea-model.ts` 校验恰好三版、拒绝重复提示词、对超时标记 `unknown`，模型密钥仅从 API 配置读取。以上是源码观察，不代表验收通过。
- 审查时 `packages/ui-web/src/PromptIdeas.tsx` 每次请求均生成新 UUID。模型收到请求而浏览器丢失响应时，页面再次点击会变成新请求。`apps/api/src/prompt-ideas.ts` 在 API 进程崩溃后也没有处理遗留 `pending` 的恢复路径。两项风险已交给前后端修复，按 IDEA-02a／02b 独立复测。
- 隔离验收采用 `mktemp` 创建专属 `API_DATA_DIR` 与固定的本机环回端口；模拟 Chat Completions 端点返回 `choices[0].message.content` 中的 JSON，记录每次 POST 的时间、请求体摘要与次数，支持正常三版、重复版、格式错误、HTTP 500、悬挂响应、断开连接。凭证为本地测试占位值；不能混入用户现有数据库或真实模型密钥。
- API 检查顺序：注册 A/B → A 无项目提交灵感 → 比较模型调用数、项目数、`agent_runs`、`operations` 和额度 → 并发同 ID／改输入 → 故障注入与重启 → A/B 权限检查。网页检查顺序：空首页 → 三版选择和编辑 → 丢失响应／刷新恢复 → 项目库创建和失败重试 → 分集／照片／审批。桌面在网页与 API 契约稳定后用真实 Tauri 窗口验收，截图只取真实客户端。
