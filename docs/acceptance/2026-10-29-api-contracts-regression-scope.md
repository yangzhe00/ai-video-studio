# 共享 API 协议回归范围（2026-10-29）

## 测试目标

验证 `@ai-video/api-contracts` 接入后，Web、桌面和移动端与 API 的现有链路仍能使用；错误增加 `code` 后，旧版 `{ error }` 仍能被客户端读取。测试使用本地隔离账号和模拟供应商；不要为普通回归触发真实付费视频生成，也不要在截图中显示密钥、Cookie 或用户密码。

## 核心用例与证据

| 编号 | 操作及预期 | 证据 |
