| 领域 | 具体检查点 | 必要证据 |
| --- | --- | --- |

| 无照片与参考图 | 关键词不附照片仍能生成故事和分镜；参考图未就绪、失效或无权限时前后端均禁止拍摄确认；三镜参考来源与角色/风格锚点可追溯，不凭空引用照片。 | 真实供应商能力与失败案例、状态校验测试、E04/E05。 |
| 报价与费用上限 | 服务端签发三项 5 秒明细、币种/来源、总上限、有效期和分镜修订哈希；确认时重新校验账号、项目、参考、额度、报价和哈希。编辑分镜或价格变化使旧报价失效；未知价格不得当 0 元放行。重做单镜需要新报价和确认。 | 价格来源、并发额度/过期/改价测试、E05/E09/E10。 |
| 确认幂等与付费提交 | 同一确认 ID 与同一输入仅对应一组已批准三镜任务；同 ID 不同输入返回冲突。三条提交意图先持久化，再由受控 worker 调供应商；重复点击、丢失响应和进程重启不重复付费 POST。未知状态先查询原任务。 | 事务与唯一约束、故障注入、供应商请求计数、E05/E06/E10。 |
| 进度与恢复 | `storyId/runId/operationId/remoteTaskId` 各有稳定语义；刷新、断网、跨端重开从持久快照与事件序号恢复。状态未知不显示假成功/假失败，事件只暴露该账号可见的数据。 | 事件重放/重连测试、持久化记录、E06/E10。 |
| 画布与时间线 | 一故事归属一个明确项目与分集；三镜顺序、稳定节点/连线 ID 和时间线片段 ID 同源。三次成功后按序形成 15±0.5 秒可播放初稿；一镜失败保留其他两镜，但不得标为完整成片。 | DSL/同步/迁移测试、同一运行的画布与时间线快照、E04/E07。 |
| 重做、渲染与导出 | 单镜重做只改变该镜，原片与已选时间线版本保留；新结果须由明确选择替换。导出 MP4 使用可恢复任务，失败不损坏已有预览/文件，重试不重复创建不必要的渲染。 | 版本/文件回滚测试、独立打开 MP4 的元数据与画面、E08/E09。 |

| 跨端与错误状态 | Web/桌面共用故事协议；移动端只提供线性分镜、进度和结果，不伪装画布编辑。未登录、空输入、供应商错误、断网、额度不足、报价过期、单镜失败和导出失败均有可执行下一步。 | 三端构建/启动、真实页面与设备截图、状态/键盘/窄屏测试、E01–E09。 |

## 公开文案闸门

官网 `apps/website/` 与 `README.md` 必须审查同一发布批次、同一候选版本、同一统计口径。逐项核对 PRD 第 8 节：

- [ ] **15 秒 / 3 镜头：**真实导出 15±0.5 秒；若要宣称三段叙事质量，至少 30 个不同输入、3 名盲评且 ≥80% 可辨起因/变化/结果。
- [ ] **新手 90 秒：**24 名首次用户，其中至少 12 名无视频编辑经验；报告主动操作时间中位数，明确不含等待。
- [ ] **确认后 10 分钟：**至少 100 次真实供应商任务，P50 ≤10 分钟且 P90 ≤20 分钟；保留失败与重试分母。
- [ ] **¥39.9：**真实直连供应商与参考图、存储、支付、税费、失败重试成本和用户支付/退款规则已核对。目标价不得充当实际售价。
- [ ] **可恢复、不重复拍：**故障注入与至少 100 个真实任务记录中重复付费提交为 0，且部分失败可恢复。

未达到任一门槛时，官网和 README 都不得展示该项数字或把目标当成已实现事实；原型截图不得标成真实视频成果。上线后还需核对公网、登录、真实故事链路、下载与回滚入口，并记录部署版本。

## 执行与问题关闭规则

1. 先核对候选快照与 E01–E10 证据，再做代码审查和针对性复测；所有结论标注“已验证 / 失败 / 阻塞 / 未覆盖”，并给出文件位置、复现步骤、预期与实际。
2. **阻断/P0：**跨账号泄露、无确认或超上限付费、重复付费提交、数据损坏、旧项目不可读、无照片主路径无法拍摄或真实链路无法导出。**严重/P1：**断线恢复错误、报价失效未阻断、部分失败被标为完整成片、跨端状态不一致。其余按用户影响定一般/P2 或建议/P3。
3. 问题交给对应前端、后端或发布负责人修复；测试会话复验同一问题及关联流程后再关闭。修复后的代码和部署版本变化须重新绑定证据，不能沿用旧候选的通过结论。
4. 代码门禁按仓库实际命令执行 `pnpm test`、`pnpm build`、`pnpm check:boundaries`、`git diff --check`；Tauri/Rust 变更补跑 Cargo 测试/检查与桌面启动。命令通过不代替 E01–E10 真实端到端验收。
