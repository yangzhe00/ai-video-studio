## 尚不能上线的门禁

1. **T01 验收口径/实现冲突**：现行范围要求旧单镜头长表单入口下线，最终候选仍可从创作页进入。需由产品明确保留范围并更新验收口径，或由前端改入口后再测。
2. **交互与一致性缺证据**：真实拖放/两端裁剪/吸附与写请求、原生和 Web 的人工听辨及启动延迟、即时音量与成片对比、断网重试和退出账号草稿、窄屏横向滚动/键盘焦点、原生旧项目、账号切换/过期预览仍未测。自动化无法完成真实拖放与系统声音采集，需人工或有相应能力的测试环境补验。
3. **供应商依赖**：真实 TTS 和整集 Agent 模型未配置，分别保持 T07、T10 阻塞。
4. **发布边界**：全部证据来自本机隔离 API、Web 和重新打包的原生应用；未对公网部署、真实用户账号、正式签名/公证安装包做验收。
