# 整集可视化时间线：测试范围与证据要求

## 环境门禁

测试先记录 Web、桌面、API、共享契约的候选 commit 或源码归档 SHA、数据库 schema、使用的账号/项目以及供应商配置状态。原型截图不算实现截图。将单元/模拟、隔离 API、原生桌面、真实供应商、公网部署分别标注。

## 用例

| ID | 操作与预期 | 必需证据 |
| --- | --- | --- |
| T01 入口与旧页下线 | 画布点“整集时间线”进入同一分集全屏页；结果页选择片段加入分集后进入该页；旧网页弹窗、桌面独立配音页和单镜头长表单入口不再出现；未登录/未同步/空分集有可恢复引导。 | Web/桌面入口、空状态截图。 |
| T02 多轨完整显示 | 新建 15 秒、3×5 秒画面，加入 2 段语音和 1 段音乐；所有已保存片段、起点和波形可见，镜头切点为 5 秒/10 秒。历史多段数据不能只显示第一条。 | 全屏时间线截图、保存前后项目快照。 |
| T03 拖动与裁剪 | 语音从素材库拖入配音轨，片段移动、两端裁剪、0.1 秒精确输入和键盘移动；落点靠近切点/播放头吸附。越界明确询问裁到结尾或取消，源资产不变。 | 拖放后、越界提示、右侧属性截图；数据时间值。 |
| T04 镜头绑定与排序 | 新语音默认跟随所在镜头；重排镜头后相对偏移保持。跨镜头旁白设“固定在整集时间”后，镜头重排不移动它。旧无锚点语音保留原绝对位置并提醒核对。 | 重排前后截图与持久化时间/锚点记录。 |
| T05 即时试听 | 从 0、4.9、5.0、10.0 秒启动/拖动播放头，画面切换连续，可听见原声、语音和音乐；静音/音量即时反映。已缓存 15 秒素材启动目标 ≤1 秒，导出起点偏差目标 ≤150 毫秒。若不支持即时试听，显示原因并保留精准预览入口。 | 带时间的页面录屏或截图、试听测量及人工听辨记录。 |
| T06 保存与冲突 | 拖动过程中无连续写请求，松手后一次保存；刷新恢复。撤销/重做一整次拖动。断网保留本地草稿，另端修改返回冲突而不覆盖；切项目/退出账号时不丢失未保存修改。 | 保存中、失败、冲突截图；网络/API 请求与前后修订。 |
| T07 上传与 TTS | WAV/MP3/M4A 有效文件上传为 voice，音乐为 music；空、伪装、超限、跨账号素材失败。文字配音显示费用说明、二次确认、等待/查询原任务；取消不提交。供应商未配置时清楚说明并允许上传录音。 | 上传/错误/TTS 确认或真实阻塞截图，脱敏任务 ID/费用状态。 |
| T08 精准预览与导出 | 已保存同一修订完成服务端预览，再导出独立 MP4；导出文件有 H264 视频和 AAC 音轨；语音跨切点不断裂，原声/语音/音乐与即时试听时间和音量一致。编辑后旧预览失效，重复点击不创建不同成功任务。 | 预览、导出、成片播放截图；MP4、ffprobe、时间/音轨分析。 |
| T09 历史兼容 | 旧 5/10 秒镜头、分集多段 voice/music、旧单镜头已混音版可打开并导出；没有重复叠音、丢段或被新页面改写原始素材/旧版本。 | 迁移前后数据及旧成片/新成片截图。 |
| T10 Agent 建议 | 新编辑页可打开整集 Agent 建议；建议引用最新分集修订、逐条确认，不自动触发渲染/TTS/额度。旧修订建议产生冲突并保留人工修改。真实模型不可用时标阻塞，人工剪辑正常。 | 建议、差异、确认/冲突截图，任务/额度只读快照。 |
| T11 布局和键盘 | Web/桌面 1440×900、900px 窄窗口，浅/深主题；时间线能横向滚动，字幕/按钮可读，键盘焦点清楚。移动端本轮仅验证项目文档读取，不把它计作多轨编辑通过。 | 四组 Web/桌面截图、键盘操作记录。 |
| T12 异常恢复 | 音频素材失效、服务端预览失败、导出失败、切换账号、预览过期：显示具体原因，保留已保存配方、原片与上一次成功成片；恢复后查询原任务或重试。 | 错误与恢复截图、operation/asset 记录。 |

## 交付格式

测试会话提交一份带日期的报告：每项写“通过／失败／阻塞／未测”、候选版本、环境、步骤、预期与实际、截图绝对路径。对失败项提供最小复现；前后端修复后在新候选版本重测。末尾单列尚不能上线的门禁。报告必须包含至少：空状态、三轨全屏、配音拖动及精确属性、播放状态、保存失败/冲突、精准预览、导出成功或真实阻塞的截图。
