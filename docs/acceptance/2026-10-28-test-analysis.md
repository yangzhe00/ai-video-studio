### 当前红项：网页云项目测试数据与文档契约不一致

`apps/web/src/App.test.tsx` 的第二个测试提供了没有 `timeline` 的分集。`cloudTimelineClips` 在 `packages/project-core/src/sync.ts` 读取 `episode.timeline.length` 时抛出异常，导致测试页面卸载。服务端新建项目会包含 `timeline: []`，旧云文档在数据库迁移时也会补齐该字段。因此当前证据首先指向测试数据不符合服务端文档契约；客户端对缺字段响应没有降级处理也值得单独验证。该失败阻断 `pnpm test` 总门禁，尚不能据此断言正常服务端返回会导致网页崩溃。

## 测试数据

- 两个独立账号、两个客户端会话、同一账号的桌面／网页／移动端会话。
- 人物和动物参考照片各一张；有效 JPEG、PNG、MP4、音频各一份；损坏文件、扩展名与内容不符文件、重复素材各一份。
- 含两个分集、两个以上镜头和重复使用同一素材的项目；另备 V1 旧项目和缺失源文件的项目。
- 大于 100 MB 的可预览视频、较长时长视频、近画布节点上限的项目；保留源文件哈希供一致性校验。
- 可控的供应商模拟：提交成功、明确拒绝、响应丢失、查询处理中、查询成功、下载失败和重复回调。

## 用户端到端用例

P0 为核心流程与数据／费用安全门禁；P1 为重要异常、跨端与性能验收。以下均为**待真实客户端执行**，现有单元或集成测试只提供部分覆盖。

| ID | 优先级 | 场景与操作 | 预期结果 |
| --- | --- | --- | --- |
| QA-01 | P0 | 新账号注册、登录、退出、过期会话后重登；使用错误密码。 | 登录状态正确；过期或错误凭据不能访问项目；提示可理解且不泄露项目内容。 |
| QA-02 | P0 | A、B 账号分别访问对方项目、素材、任务和渲染结果。 | 所有跨账号访问被拒绝；列表和预览不暴露对方数据。 |
| QA-03 | P0 | 桌面新建项目、导入素材、保存、退出并重开；随后移动或删除项目目录。 | 正常重开保持数据；路径失效时给出可恢复入口，不静默新建或覆盖旧项目。 |
| QA-04 | P0 | 导入人物／动物照片、视频和音频，再导入损坏文件、伪装扩展名文件和重复文件。 | 有效素材进入项目且源文件哈希不变；无效素材被明确拒绝；失败不留下半成品记录。 |
| QA-05 | P1 | 导入大于 100 MB 视频并尝试预览、切换项目、保存。 | 当前预览限制有明确提示；素材和项目仍可保存、重开；界面不长时间无响应。 |
