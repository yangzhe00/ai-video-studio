# 桌面发布包云端地址故障

2026-11-04，用户从官网下载安装 `AI-Video-Studio-0.1.0-macos-arm64.dmg` 后，在桌面端注册时看到请求发往 `http://127.0.0.1:8787/auth/register` 并失败。该 DMG SHA-256 为 `db2dbf78c874ac4f7dad6a8ddd06c0d374f52f7fbb17256f6e007e160ede8506`，与当前公网 `/downloads/latest.json` 一致。

`apps/desktop/src-tauri/src/cloud.rs` 在运行时环境变量缺失时默认连接本机 8787。已安装应用不会继承开发机的进程变量，注册、登录、项目、任务、上传和下载共用该地址构造函数，因此均受影响。网页端以同源 `/api` 发起 API、媒体与 SSE 请求，Vite 的本机 8787 代理仅用于开发。正式公网 `https://39.108.55.176/api/health` 在本次检查时通过正常 TLS 验证并返回 `{"ok":true}`。

修复要求：发布包内必须有公开的正式 API 基址；缺失配置的发布构建不能悄然指向本机；开发构建仍可连接本机 API。发布时生成新版本 DMG，保留旧版本不可变文件，核对源码 SHA、包 SHA、真实安装包的注册/登录、项目、素材及预览请求目标。生产账号和密钥不得进入构建配置或日志。
