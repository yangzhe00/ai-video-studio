# 整集剪辑 v3：按片段编辑画面与镜头原声

日期：2026-11-02。状态：产品设计与开发交付稿。可点击原型：`design/prototypes/episode-clip-editor-v3/index.html`。本稿叠加于既有整集剪辑 v2 的时间尺、AI 视频编辑、配音与音乐能力；Web 与 macOS 桌面同一规则，移动端本轮只读取成片与项目。

## 1. 问题与代码证据

用户给出的时间线结构中，画面只有不可操作的镜头块，镜头原声只有一个全局静音按钮；配音和音乐才有片段拖动/裁剪。实际共享模型 `TimelineSnapshot` 仅有 `visuals`、`audio` 和 `originalVolume`，画面写入 `orderSavedVisuals` 要求**已有片段的等长排列**，拒绝新增/分割/删除；镜头原声依靠视觉片段 `volume` 与全局 `originalVolume`，没有独立的区间片段。证据：`plugins/video-edit/src/web/timeline-model.ts:11-55,35-39`、`plugins/video-edit/src/web/EpisodeTimelineEditor.tsx:268-275`、`apps/api/src/episode-media.ts:25-50`。因此这是一项前后端共享契约与渲染改造，不能仅改 CSS 或按钮。

## 2. 设计目标与取舍

目标是让用户像常见剪辑器那样，在同一时间线上**选中任意片段 → 在播放头处分割 → 单独调整 → 删除本段 → 撤销/预览**。画面、镜头原声、配音、背景音乐都显示独立片段与选中态；右侧属性随选择切换。原始视频和音频文件一律不物理删除。

取舍：P0 的画面始终无黑场空隙，删除画面片段默认**合拢后续画面**；只删除镜头原声片段时，画面和整集时长不变，原声的该区间静音。这样新手能直接得到连续成片，且“删声音”不会误删画面。留黑场、解链后自由移动原声、多轨转场和速度曲线放 P1。删除前展示时间与音轨影响；不能在用户不知情时重排配音。

## 3. 页面交互

| 区域/按钮 | 行为 |
| --- | --- |
| 时间线轨道 | `画面`、`镜头原声`、`配音`、`背景音乐`按同一刻度排列。每个片段有标题/时长；画面用真实缩略帧，音频用真实波形。单击片段选中，边框高亮并切换右侧属性；按空白取消选中。选中片段后可用对应操作。 |
| 时间尺/播放头 | 继续支持按住拖动、单击定位、键盘 ±0.1 秒；尺拖动仅改播放位置，不产生写请求。播放头横跨四轨，分割点以当前播放头时间为准。 |
| 工具栏 `分割片段` | 仅在选择片段、播放头落在该片段**内部至少距两端 0.3 秒**时可用。画面分割后左右两段引用同一源视频不同入/出点，镜头原声也在同一源时间切开；总时长不变。镜头原声分割仅切原声，不动画面。配音/音乐分割仅切本音频片段。一次操作作为一次撤销步骤。 |
| 工具栏 `删除本段` / Delete 键 | 先显示受影响范围的确认面板；如果有不确定的音轨锚点或会越界，先处理冲突。确认后只移除所选时间线引用，不删源素材。连续重复点击/快捷键不得删除下一段。 |
| 工具栏 `撤销`、`重做` | 分割、删除、裁剪、移动、静音、音量等一次用户动作算一步。保存中/失败时本地草稿仍可撤销；与云端冲突时须先解冲突，不静默覆盖。 |
| 工具栏 `吸附`、缩放 | 吸附到 0、镜头切点、音频端点和播放头；拖边裁剪/移动显示毫秒换算后的 0.1 秒读数。缩放与水平滚动不能改变数据时间。 |
| 右侧画面属性 | 显示镜头标题、源素材、整集起止、源素材入/出点、片段时长。支持拖两端或输入数值裁剪、`前移`/`后移`（拖动排序为同等入口）、`AI 编辑此片段`和`删除本段画面`。裁剪/排序后预览受影响的音轨位置，再保存。P0 不做任意空隙移动。 |
| 右侧原声属性 | 显示所属画面片段与同源视频范围、整集起止、单段音量 0–200%、`静音此段`、`恢复此段`、`删除此段原声`。可拖两端缩短有声范围，不能移动到源视频未覆盖的时间。全局原声总音量保留为轨头设置，明确“先乘全局再乘片段音量”。 |
| 右侧配音/音乐属性 | 保留现有起点、入点、出点、音量、锚点、移动、裁剪、删除；新增同一套`分割片段`。删除音频不改变画面总时长。 |
| 播放/精准预览/导出 | 即时试听读当前本地草稿；服务端精准预览与导出读已保存分集修订。任何片段编辑使旧精准预览失效。AI 视频编辑返回版本后，该版本仍作为一个画面片段参与分割/删除。 |

### 分割/删除语义

| 被选中轨 | 分割后 | 删除本段后 |
| --- | --- | --- |
| 画面 | 生成左右两个稳定片段 ID，源视频 ID 不变；源入/出点连续，镜头原声按源时间同步分为左右段。原有字幕/封面/AI 结果引用要与新片段对应，后端给出兼容策略。 | 视觉时间线合拢，后续视觉与所属镜头原声前移；被删画面的原声区间随画面移除。总时长减少本段长度。原片在素材库保留。 |
| 镜头原声 | 生成两个独立原声区间，仍引用所属视觉片段的原视频音轨。 | 仅该区间静音；画面、配音、音乐和总时长不变。素材仍保留，可撤销或重新启用。 |
| 配音 | 生成左右两条对同一 voice 素材的引用，出入点无缝衔接。 | 只移除所选 voice 片段；画面与其他音频不动。 |
| 背景音乐 | 同配音。 | 只移除所选 music 片段；画面与其他音频不动。 |

画面合拢时，**锚定在仍保留镜头上的配音**跟随镜头移动；固定在整集绝对时间的配音/音乐保持原秒数，但对可能错位的片段展示提示。若被删画面上有锚定配音，确认面板要求用户选择“同时移除该配音”或“保留并固定到整集时间”。任意音频若越过新结尾，确认面板须逐条列出并要求用户选择“先返回调整”或“明确裁剪超出部分”，不能静默截断。最后一个画面被删除时，如果还摆有音频，要求先移除/转回素材库的时间线引用；项目素材本身保留。

边界：P0 片段长度不得低于 0.3 秒；在端点或空白处分割禁用；无原声音轨的视频显示“此镜头无原声”，不创建假波形；相邻同源片段可以并列，不能被自动去重；旧已混音语音仍是视频原声，不自动重复加到配音轨。音轨锁定时禁止对应编辑。所有时间使用整数毫秒保存、界面显示 0.1 秒。

## 4. 前后端改动边界

**架构/后端**先定义可持久化的源音频片段模型：每段有稳定 ID、所属视觉片段/源视频 ID、源时间范围、在分集内的映射、音量/静音状态。旧项目默认投影为每个视频片段一条虚拟原声；首次编辑时升级为可写版本。具体字段由架构决定，但必须满足“原声可独立分割/删除、视频可分割/删除、旧项目可读、Web/桌面相同结果”。更新画面写入校验（目前只允许排列）、音轨锚点迁移、合成预览/导出对静音区间与分段的渲染、幂等命令、分集修订与跨端冲突。源文件、旧版本与上一次成功成片不得被删除。

时间映射必须可复算：若视觉片段在整集起点为 `S` 毫秒、源视频入点为 `I` 毫秒，原声源区间 `[a,b)` 在整集对应 `[S+a-I,S+b-I)`。裁剪或重排画面后按此式重算，不能靠浮点累计或上次界面坐标。旧 `visual.volume` 是每镜头原声增益；迁移时作为新原声片段的默认增益，播放与导出只应乘一次，再乘整集 `originalVolume`。已混音入源视频的旁白仍属于该源原声，不自动复制到配音轨。所有区间使用左闭右开整数毫秒，输出采用确定的同一时间轴。

**前端**在共享 `EpisodeTimelineEditor` 中让四轨都可选中，提供工具栏与随轨道变化的属性区，分割/删除前影响确认，画面/原声拖边、画面重排、原声单段音量/静音、键盘操作、撤销/重做。视觉片段可与 `AI 视频编辑` 工作台互通；新片段的真实缩略帧与原声波形必须能更新。不得把“静音整集”伪装成“删除一段原声”。

**集成顺序**：先冻结旧数据样例与共享契约，后端支持新分段读写/渲染后前端接入真实保存，再由测试固定候选做 Web、原生、服务端媒体回归。前端可并行制作 UI，但不能在没有后端契约时把模拟分割标成完成。现有 v2 的 AI 视频编辑、TTS、拖尺开发继续，合并时避免覆盖并行改动。

## 5. 验收

1. 3×5 秒镜头，在 7.3 秒选中第二画面并分割，画面变成 5.0–7.3 与 7.3–10.0 两段，原声对应同步分割；整集仍 15.0 秒。删右段并确认合拢后，整集为 **12.3 秒**，原片可找回；撤销后回到 15.0 秒。
2. 恢复 15 秒样例；只选第二镜头原声，在 7.3 秒分割并删 7.3–10.0 段，画面仍 15 秒，7.3–10.0 秒原声静音，其他时间原声/配音/音乐仍可听，导出 MP4 与试听一致。
3. 第一段原声音量改为 30%，其他段保持原值；刷新、Web/桌面互看、精准预览与导出均一致。无源声音频不能显示可编辑假片段。
4. 配音/音乐分割与单段删除只影响所选片段；源素材、其他段和整集长度不变。重复按钮/键盘、分割近端点、最后画面、被删画面有锚定配音、旧项目、跨端冲突均有明确可恢复结果。
5. 测试会话提交固定候选版本、运行中 Web/原生的选择/分割/删除/属性/确认/撤销截图，真实 MP4 的时间和音频区间分析；原型图、模拟波形或单元测试不能替代实际结果。

## 6. 原型说明

原型可演示选择四轨、拖时间尺、分割、删除、单段音量/静音、画面裁剪/排序、撤销与影响提示。视频、波形、保存、精准预览和导出为模拟；不产生媒体文件或服务端写入。
