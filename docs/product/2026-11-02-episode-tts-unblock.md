# 整集剪辑：文字生成旁白进入配音轨——现状诊断与修复要求

日期：2026-11-02。产品确认：用户要的是**输入文字生成旁白，放到配音轨**；不是输入文字生成背景音乐。P0，Web 与 macOS 桌面均须可用。此文作为《整集剪辑 v2》增补需求。

## 2. P0 交互

1. 左侧素材库分为`配音`与`背景音乐`。在`配音`标题下放两个并列动作：`上传录音`、`文字生成旁白`。音乐区只保留`上传背景音乐`。按钮文案在页内、任务和结果中统一使用“旁白”。
2. 点`文字生成旁白`打开侧面板/弹层：输入中文文案（1–1000 字）、选择**已实际验证**支持中文的音色、语速、试听已有音色样本（若供应商提供）；显示“生成后进入配音素材库，由你决定放到时间线哪里”。输入为空、无可用中文音色、未配置服务时不能点费用确认，并给明确原因与`上传录音`退路。
3. 点`查看费用说明`返回服务端真实金额或“按供应商实际用量结算”，不得填假金额。再点`确认费用并生成旁白`才创建任务。处理中可关面板；刷新/断线/桌面重启后查询**同一个**任务，不自动重提可能收费的请求。
4. 成功后在配音素材库显示音频时长与试听按钮，明确`加入配音轨`；点击默认放到播放头所在时间，落点/越界规则沿用整集时间线。不得自动放入音乐轨，不得自动导出。用户仍可拖动、裁剪、调音量，再做精准预览/导出。
5. 错误按原因分层：`服务未配置`、`音色不可用`、`账号/地区无 TTS 权限`、`余额/额度不足`、`任务失败`、`任务提交状态未知`。未知状态只允许查询原任务，不能显示“重试生成”造成重复扣费。

## 3. 后端与架构修复范围

1. 对当前**本机与待上线服务器**分别只读检查 TTS 相关配置的存在性、目标区域、worker 状态，不打印密钥。核对官方开发者控制台/文档中的账号区域、TTS 路由、认证方式、可用中文音色 ID 与计费条件；输出证据。若当前账号没有 TTS 权限，给出可行供应商方案与费用/合规约束，不用未经验证的音色 ID 或把视频 key 当通用 key。
2. 在独立服务端密钥 `KLING_TTS_API_KEY` 和可验证音色列表具备后，先做**不产生费用**的鉴权/权限检查（若供应商有此接口）；再经测试账号确认额度后只提交一次真实中文短文案。记录服务端任务 ID、供应商任务 ID、成本状态、音频资产与媒体探测；不在仓库、日志、截图中暴露密钥。
3. 复核 `/tts/voices` 在“配置存在但认证不可用”时的表现，避免把无效音色展示成可用；`estimate` 与 `submit` 必须同一音色、文字、费用确认和稳定 `clientRequestId`。同步失效/未知提交先查原任务。成功资产类型必须是 `voice`，供 Web/桌面加入配音轨。
4. 如换供应商，保持共享 TTS 契约与任务幂等/费用门禁，先由架构给出真实接口与价目证据，再实施；不通过 mock 证明真实旁白可用。视频生成配置不得被 TTS 调整破坏。
