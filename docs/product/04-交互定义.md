## 1. 端型矩阵

| 端 | 结论 | 理由 |
|---|---|---|
| Web 桌面端 | ✅ 一期唯一端 | 内部创作工具，核心操作是大屏上的编辑（讲稿编辑、提示词调整、逐段关联图文），大屏效率远高于手机 |
| 移动端 H5/App | 🚫 一期不做 | 无"必须在手机上完成"的任务；唯一移动场景是"下载成片发到手机发布"，可用 Web 传文件替代；弱网下上传大图/查看视频体验差 |
| 小程序 | 🚫 不做 | 同上，且内部使用无小程序分发诉求 |

跨端任务：无。所有任务单端（Web）闭环，不存在端点切换与同步时机问题。

## 2. 信息架构（Web 端页面清单）

```
登录页 /login
工作台（首页）/home
 ├─ ① 选题与讲稿 /topic          （A 域：选题灵感、讲稿编辑、分镜提示词）
 ├─ ② 素材库 /assets             （B 域：素材上传、站内生图）
 ├─ ③ 生成任务 /generate         （B 域：图文关联、提交生视频、片段管理）
 ├─ ④ 合成工作台 /compose        （C 域：模板选择、配音、字幕、提交合成）
 ├─ ⑤ 成片库 /output             （D 域：预览、下载、版本历史）
 ├─ ⑥ 任务中心 /tasks            （E 域：全站异步任务看板、失败重试）
 └─ ⑦ 用量与额度 /usage          （E 域：消耗记录、额度预警）
```

- 全局导航：左侧固定导航栏（7 个一级页面），右上角用户信息与退出
- Web 分辨率适配：1366×768 / 1440×900 / 1920×1080 三档可用，内容区最大宽度约束，不为填满 1080p 而拉高容器 ✅

## 3. 黄金任务流（端到端，对应 PRD 验收）

```
登录 → ① 输入关键词生成选题 → 选定选题生成讲稿 → 分段编辑确认
     → 生成分镜提示词 → ② 上传/生图准备图片素材
     → ③ 逐段关联「图片+提示词」→ 提交生视频任务（额度预检）
     → 任务中心/页内等待片段生成 → ④ 选模板 → AI 配音试听确认
     → 字幕自动生成（可改字）→ 提交合成任务 → 成片入库
     → ⑤ 预览成片 → 下载 mp4 → 手动发布到平台（站外动作）
```

关键交互规则：
- 任务流支持**中断续作**：每一步结果自动保存，可从任务中心跳回任一步骤继续
- **额度预检**在提交生视频/生图任务前执行（FR-E-03），不足时阻断并显示余额
- 长时任务（生视频、合成）不阻塞页面，用户可离开，任务中心查看进度

## 4. 七类交互状态（关键页面覆盖表）

| 状态 | ③ 生成任务页 | ④ 合成工作台 | ⑥ 任务中心 |
|---|---|---|---|
| Loading | 任务卡片显示排队位次/进度 | 合成进度条（百分比 ⚙️ 待研发确认精度） | 列表骨架屏 |
| Empty | 无片段：引导去素材库 | 未选模板：模板选择器置顶引导 | 空态说明+去选题按钮 |
| Error | 失败原因分类标签+重试按钮 | 合成失败列出缺失/失败要素 | 失败筛选器+批量重试 |
| Partial Success | 部分段成功部分失败：成功段标记可用，失败段单独重试 | 同上 | 任务分组展示 |
| No Permission | 访问他人数据返回无权限页 | 同左 | 仅本人数据 |
| Disabled | 额度不足时提交按钮禁用+余额提示 | 要素缺失时提交按钮禁用+缺失清单 | 失败任务重试按钮在参数错误时禁用（需先修改） |
| 待人工确认 | 重新生成覆盖确认 | 配音试听确认、字幕修改确认 | — |

## 5. 页面模式与示例数据（跨页面自洽）

统一示例：领域「居家收纳」，选题「3 个让衣柜翻倍的收纳神器」，讲稿 5 段，素材 5 张，片段 5 条，模板「简约生活风-白」，成片时长约 60 秒（数值均为示例演示，非业务规则）。示例数据不含真实个人信息。

## 6. 交互一致性

- 全站按钮命名统一：主任务按钮用动词短语（"生成讲稿""提交合成"），不用"开始""搞定"
- 数据口径统一："片段"=单条生视频结果；"成片"=合成产物；"任务"=任一异步操作。各页面命名与 PRD 一致
- 状态色统一：成功绿 / 失败红 / 进行中蓝 / 排队灰

## 7. 设备能力使用说明（Web 端）

- 文件选择器：素材上传（对应真实业务需求 FR-B-02）
- 视频播放器：片段与成片预览（FR-B-04、FR-D-01）
- 不使用：摄像头/定位/通知等（无对应业务问题，避免堆砌）✅
