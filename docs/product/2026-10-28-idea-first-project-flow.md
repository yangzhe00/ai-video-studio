# AI Video Studio：一句话灵感与项目入口交互方案

状态：产品方案，供架构评估与前后端、测试拆分。2026-10-28。原型：`design/prototypes/idea-first-project-flow/index.html`。原型只模拟交互，不调用真实模型或付费视频服务。

## 问题与目标

1. 新手有一句想法或几个关键词，但不知道如何写视频生成提示词。让 Agent 先提供**同一镜头的三版不同创意方向**，用户选一版并可编辑，再进入视频生成。
2. 网页首页当前直接嵌入“我的项目”按钮、项目名称输入框和分集列表；项目增多后首页失去焦点。桌面首页没有这块列表，入口不一致。
3. 桌面创建本地项目与云端出现项目是两件事。当前用户确认桌面端未登录，本次网页看不到该项目是符合现有逻辑的，不作为后端同步缺陷处理。入口文案仍应说清“仅在本机”。

成功标准：用户能从首页输入一句话，在不创建项目、不消耗视频生成额度的情况下得到三种镜头提示词；选择并确认后才创建或选定项目、照片、分集并发起一次视频任务。首页不显示整张项目与分集列表。桌面未登录时明确标记项目只在本机。

## 方案与取舍

| 路线 | 取舍 |
| --- | --- |
| 继续把项目列表和新建表单放在首页 | 修改少，但首页会随项目增长而拥挤，且新手必须先理解项目与分集。 |
| **首页先写想法；项目集中在项目库；选择提示词后再选／建项目** | 最贴合“一句话获得灵感”，需要账户级草案持久化和明确的项目归属步骤。本方案采用。 |
| 首次输入时静默创建项目 | 少一次点击，但会产生无名项目，与用户要求清楚管理项目的方向冲突。 |

## 交互流程

```text
登录首页 → 输入一句话／关键词 → Agent 生成三版单镜头提示词
       → 选一版并修改 → 选择已有项目或明确新建项目
       → 选择已有分集或明确新建分集 → 选择／上传参考照片
       → 检查最终提示词、5／10 秒和演示额度 → 用户确认
       → 复用现有生成任务 → 查看状态和结果
```

用户可以从现有项目工作台直接进入“三种灵感”，此时项目与分集预选但仍可更改。选中一版不提交视频任务；改动提示词后保存最终文本快照。没有照片时可以先构思，但在生成确认前必须提供可用照片。输入不能为空；建议前端限制为 1–200 字，后端按最终长度校验并避免返回空白、完全重复的候选。

三张候选卡各包含：简短方向名、用一句话解释画面效果、可编辑的完整单镜头提示词。默认方向应明显不同，例如叙事、情绪、节奏；不承诺特定模型一定能实现所有动作。用户可重新获取三版；旧草案仍可找回。模型缺失、超时、限流时展示真实失败与重试，不将固定文案冒充为 AI 生成结果。

灵感草案归属于当前账号，在没有项目时也能保存；刷新或换设备后可找回，跨账号不可见。用户已选定后端先做**可配置的 OpenAI 兼容文字模型接口**，以模拟服务验收，真实模型地址、名称和密钥只在 API 进程配置。生成三版会消耗平台模型资源，但**不消耗用户的视频生成演示额度**。后端应限流并记录调用成本。选择某版、创建项目或仅连接画布均不产生视频生成操作；只有用户确认最终镜头计划时才进入现有付费任务审批。未来若改为需要项目才能保存草案，应作为单独产品决策，不在实现中默默改变入口。

## 首页与项目库

- **首页**：保留一句话输入和最近一个项目的继续入口；另有“全部项目”。项目列表、行内新建输入框、分集列表均不放在首页。没有项目时仍能先获取三种灵感。
- **项目库**：独立页面，按最近更新排序；有项目名称、最近一集、更新时间和可用状态。提供搜索、空态、加载态、失败重试和“新建项目”。分集只在打开项目后展示。
- **新建项目**：使用清楚的弹窗／独立步骤输入名称，用户明确提交；成功后进入该项目的创作工作台，不留在首页。不可重复提交。网页创建的是当前账号的云项目；桌面登录时显示目标账号与云关联状态，未登录时明确标为“仅保存在本机”。
- **桌面云关联**：本轮不改同步协议。桌面未登录创建的是本地项目，提示“仅保存在本机；登录后可关联云端”。已登录但未完成关联时不可显示“已同步云端”。
- **网页项目库刷新**：进入项目库时重新查询 `/projects`，另提供手动“刷新”。本轮不做桌面到网页的自动实时列表推送。

## 桌面入口状态文案

| 状态 | 用户文案 | 下一步 |
| --- | --- | --- |
| 未登录 | 仅保存在本机 | 登录并选择是否关联云端 |
| 登录但未关联 | 尚未同步到云端 | 关联到当前账号 |
| 关联中 | 正在上传／同步 | 等待完成，避免重复创建项目 |
| 已同步 | 已同步到云端 | 可在网页同账号项目库打开 |
| 失败或冲突 | 同步未完成：具体原因 | 查看现有错误或冲突处理入口 |

状态文案由已验证的绑定和最近一次同步结果决定，不由“账号已登录”推断。网页只列当前账号、当前服务端的云项目；本地未关联项目不会凭空出现。

## 验收标准

1. 首页输入关键词得到**三版单镜头提示词**；三版不完全重复，可分别编辑、选择、取消和重新获取；刷新后可找回草案。
2. 获取三版与选择其中一版不创建 `agent_runs` 或视频 `operations`，不扣视频演示额度；最终确认后只创建一条生成任务。灵感请求超时后，同一请求 ID 只查询原草案状态，不能自动再次调用可能已收款的文字模型；用户明确要求重新获取三版时才用新请求 ID。
3. 没有模型凭证、模型响应异常、限流、离线、额度不足及照片缺失均显示可理解的状态，不能显示伪成功或偷偷改用模板。
4. 网页首页不含项目行内表单与分集列表；项目库可新建、搜索、刷新、打开项目；创建成功进入创作工作台。桌面首页同样不显示整张项目列表。
5. 桌面未登录创建项目后，网页不显示该项目且桌面显示“仅保存在本机”；不把此现象报成后端同步缺陷。桌面已登录但尚未关联时，不显示“已同步云端”。
6. 用两个账号验证项目、草案、素材和任务的所有权隔离；用真实桌面窗口和浏览器完成新建项目、返回首页、进入项目库和三版提示词的验收，并保留截图。

## 当前实现边界

目前 `agent-core` 只把单镜头输入校验成 `validated-input` 计划，没有生成三版提示词的模型能力；API 仅有视频生成任务与审批链路。网页新建项目成功后打开生成页；首页项目列表是返回首页后显示的。桌面新建项目先创建本地目录；本次用户确认未登录，因此网页看不到它是预期行为。此文及 HTML 原型描述目标体验，不能当作现状或测试通过记录。
