# AI Video Studio：首页统一创作入口 PRD

日期：2026-10-29  |  版本：V1.0 开发交接稿  |  关联设计：`docs/superpowers/specs/2026-10-29-unified-home-creation-design.md`

## 0. 决策、现状与目标

**用户已确认**：首页采用**一个输入框、两个动作**。没有灵感的人输入关键词，由 Agent 提供三个**同一镜头**的不同提示词；已有灵感的人输入自己的提示词或完整剧本，直接开始。两条路径都汇合到项目归属和制作方式选择。完整剧本在画布中保存原文，由用户手动拆镜；本版不自动拆镜。

**当前代码已具备**：账号级三版灵感草案、选中并编辑提示词、可配置的模型提供方、项目库、单镜头计划与审批、画布逐节点运行、时间线。**当前代码缺口**：首页仍把灵感卡与建项目入口并列；手写内容没有完整的项目交接；项目没有可找回的创作原文；网页创建项目仅提交名称和空分集；桌面本地创作原文也未进入云同步资源。以上是开发任务，不得在验收前写成已上线能力。

**现状证据链**：`packages/components/src/ProjectHome.tsx` 同时渲染 `ideaSlot` 和“开始新项目”；`packages/ui-web/src/PromptIdeas.tsx` 将首页输入限制为 200 字；`apps/web/src/App.tsx` 的手写路径直接转项目库/创作页；`apps/api/src/server.ts` 的 `POST /projects` 只创建标题与空分集；`plugins/canvas/src/CanvasPage.tsx` 已提供文本/视频节点和时间线；`apps/desktop/src/lib/sync.ts` 当前资源指纹仅含素材、人物、分集和画布。这些文件和已批准的[首页统一创作入口设计](../superpowers/specs/2026-10-29-unified-home-creation-design.md)共同构成开发依据。

**目标**：用户从首页输入一次内容，明确选择 Agent 或自己的内容，明确选择项目与制作方式，随后能在单镜头准备页或画布继续。每一步都知道是否会调用模型、创建项目或消耗视频额度。

**范围**：网页、桌面端共享首页体验；当前网页版项目为云项目，桌面可以建本地项目。移动端本轮只需兼容新项目字段的读取，不重做首页。

## 1. 术语与流程

| 术语 | 定义 |
| --- | --- |
| 输入原文 | 用户最初在首页输入的关键词、提示词或剧本；创建后保留，不用生成结果覆盖。 |
| 最终创作内容 | 手写路径为用户输入；Agent 路径为用户选定并编辑的单镜头提示词。 |
| 创作原文 | 项目中的持久资料，记录原文、最终创作内容和来源。它不是可直接运行的视频节点。 |
| 单镜头提示词 | 供一次 5/10 秒图生视频任务使用的文本，最多 2000 字。 |
| 项目归属 | 显式创建新项目或选择已有项目；点击首页两个动作均不自动创建项目。 |

```text
H0 首页统一输入
 ├─ 关键词 → Agent 请求 → H1 三版镜头方向 → 选/改一版 ┐
 └─ 已有提示词/剧本 ──────────────────────────────────┤
                                                     ↓
S1 开始这个作品：新建/加入项目 + 选择制作方式
 ├─ 直接生成一个镜头 → G1 照片/分集/时长/提示词 → G2 计划审批 → R1 结果
 └─ 进入画布编排 → C1 创作原文面板 → 手动建镜头 → 逐个审批/运行 → 时间线/导出
```

页面切换和打开画布都不触发视频请求。视频费用/演示额度仅在用户于 G2 点击“确认并开始生成”后按现有后端规则处理。

## 2. 页面与按钮清单

以下数量只统计**本需求涉及的主内容区交互**，不计既有左侧 5 个导航页签、主题切换、退出登录和画布原有节点工具栏。可选项数量随项目和草案数量变化，已单独注明。按钮名称为产品文案，前后端及测试按此验收。

### H0 首页：一个输入框

页面标题：**你想拍什么？**。一个可扩展文本框，标签“写下关键词、提示词或剧本”，占主视觉。说明文案：“找灵感可输入 1–200 字；已有内容可输入最多 10000 字。获取灵感不会消耗视频额度。”首屏不再放“开始新项目”按钮和独立的建项目表单。

| 序号 | 按钮文案 | 数量 | 点击条件与动作 | 到达 |
| --- | --- | ---: | --- | --- |
| H-1 | 让 Agent 给我 3 个方向 | 1 | 非空且 ≤200 字、已登录；提交或查询同一 `clientRequestId`，请求期间禁用重复提交。 | 留在首页，展开 H1。 |
| H-2 | 用我的内容开始 | 1 | 非空且 ≤10000 字；不调用 Agent，把输入快照带到 S1。 | S1。 |
| H-3 | 全部项目 | 1 | 无条件可点。 | 现有项目库。 |
| H-4 | 继续最近项目 | 0 或 1 | 有最近项目才显示；重新打开该项目。 | 上次项目工作台。 |

**数量**：固定 3 个；有最近项目时 4 个。H-1/H-2 需要输入才可用；空白时禁用，用户尝试提交时给出“先写下内容”。桌面未登录时 H-1 禁用并提示“登录后可让 Agent 提供方向”，H-2 仍可创建本地项目。输入区支持粘贴长剧本，字数提示按 Unicode 字符计数；超过 200 字仅禁用 H-1，不影响 H-2。H-1 出错后 H-2 仍可用。

### H1 三版灵感：在首页主输入区下方展开

Agent 返回恰好三张卡片，每张展示“方向名、画面说明、完整单镜头提示词”。卡片是选择按钮，点击只改变选中态，不创建项目、不调用视频服务。默认**不自动选中**。选中后出现可编辑的“最终镜头提示词”文本框。

| 序号 | 按钮文案 | 数量 | 点击条件与动作 | 到达 |
| --- | --- | ---: | --- | --- |
| I-1 | 方向 1 / 方向 2 / 方向 3（卡片标题随模型结果） | 3 | 仅 `ready` 可点；切换选中态，把该版提示词载入编辑框。 | H1 原位。 |
| I-2 | 用这条灵感开始 | 1 | 已选卡片，编辑后提示词 1–2000 字；先保存选择与编辑文本。 | S1。 |
| I-3 | 再给我 3 个方向 | 1 | 用户明确开始新一轮；生成新请求 ID，旧草案仍可找回。 | H1 加载态。 |
| I-4 | 查询原请求 | 0 或 1 | 仅 `pending/unknown` 或网络响应不确定时显示；同一 ID 查询，不重复调用模型。 | H1 状态刷新。 |
| I-5 | 另起一轮 | 0 或 1 | 仅原请求不确定时显示；须说明可能新增一次文字模型调用。 | H1 新一轮。 |
| I-6 | 最近的灵感（每条草案） | 0–3 | 查看账号内既有草案；切换前保留当前编辑内容。 | H1 对应草案。 |

**数量**：`ready` 状态固定 5 个主流程按钮（3 卡片 + I-2 + I-3），另有 H0 的按钮与至多 3 条历史草案入口；异常态按 I-4/I-5 增加。H0 的 H-1 在 `ready` 时由 I-3 复用同一位置，界面不得同时出现两个“重新获取”按钮。若用户修改首页输入，旧三版标为“与当前输入不符”，不可继续；可恢复旧输入或重新获取。Agent 失败时显示“灵感服务未配置/暂不可用/今日次数已用完”等真实错误，并允许 H-2 继续。

### S1 开始这个作品：项目归属与制作方式

显示只读的“输入原文 / 最终创作内容”摘要；手写路径的完整文本可在此编辑，Agent 路径需返回 H1 修改选定版。项目归属默认“新建项目”，预填由内容前 20 个字符生成、可修改的项目名，范围 1–50 字；名称不得为 `.`、`..` 或含 `/`、`\\`。选择已有项目时显示搜索框与当前账号可访问项目；桌面还可选择本机项目。

| 序号 | 按钮文案 | 数量 | 点击条件与动作 | 到达 |
| --- | --- | ---: | --- | --- |
| S-1 | 新建项目 | 1 | 切换到名称输入；不立即创建。 | S1 原位。 |
| S-2 | 加入已有项目 | 1 | 载入/展示项目列表；不覆盖旧创作原文。 | S1 原位。 |
| S-3 | 直接生成一个镜头 | 1 | 选定制作方式；手写内容 >2000 字时不可选，并说明“先缩短为一个镜头或进入画布”。 | S1 原位。 |
| S-4 | 进入画布编排 | 1 | 选定制作方式；长剧本推荐此项，但不替用户自动判断意图。 | S1 原位。 |
| S-5 | 返回修改内容 | 1 | 保留所有输入，返回 H0/H1。 | H0/H1。 |
| S-6 | 创建项目并继续 / 加入项目并继续 | 1 | 项目归属和制作方式均有效才可点；保存创作原文，防重复提交。 | G1 或 C1。 |
| S-7 | 项目卡片（项目名） | 0–N | 仅“加入已有项目”时展示；选定项目，不立即进入。 | S1 原位。 |

**数量**：固定 6 个，已有项目列表另加 N 张卡片。S-3/S-4 默认不选，S-6 在选择前禁用，避免误入单镜头。手写内容选择 S-3 时，另显示**非按钮**确认项“我确认这是一段单镜头描述”；勾选后才能继续。Agent 选定版无需此项。加入已有项目时还需选择目标分集；没有分集时提示创建，不得把原文覆盖到现有节点。已有项目内新增的创作原文以新记录追加，旧记录可在画布查看。

**S-6 结果**：新项目在服务端/本机保存成功后才跳转；服务端响应丢失则用相同项目 ID 查询，不自动再建一个。加入已有项目先保存新创作原文；保存冲突留在 S1，展示冲突与重试/重新选择入口。任一步失败都保留输入与所选方式。

**S1 的条件状态与按钮**：加载项目列表时显示“正在加载项目”，S-6 禁用；列表失败时增加 1 个“重试加载”；搜索无结果时显示“没有找到项目”，仍可切回 S-1；保存发生修订冲突时增加“查看当前版本”和“保留草稿返回”两个按钮，不提供未经确认的自动覆盖；创建结果不确定时 S-6 文案改为“查询原项目”，另有“另起新项目”供用户明确放弃原请求编号。按钮变体不得改变上表的正常态数量。

### G1 单镜头准备与 G2 审批

G1 复用现有创作页的数据与能力，新增从 S1 带入最终文本并可找回。首屏关键控件：目标分集选择、参考照片选择或上传、最终单镜头提示词编辑、5/10 秒时长选择。该交接路径必要按钮共 **4 个**：**上传参考照片**、**新建分集**、**检查镜头计划**、**返回作品设置**；现有创作页的其他功能按钮仍保留。其中“检查镜头计划”须项目、分集、可用照片、1–2000 字提示词完整才可点。文本来自完整剧本时不得自动截断；用户必须在 G1 明确改成单镜头描述。

G2 显示实际提示词、照片、时长、目标分集、将消耗的额度与任务状态。该审批卡必要按钮共 **2 个**：**返回修改**（回 G1，不能丢内容）与 **确认并开始生成**（按现有审批协议提交一次）。关闭/切页再回来可找回待确认计划；未点后者时 `operations=0`、视频额度未消耗。结果在现有“结果”页查看。

### C1 画布编排

进入目标分集画布时，在非执行区域增加 **1 个新按钮“创作原文”**，点击打开侧栏/抽屉，展示当前及历史原文、来源和保存时间，并允许编辑“最终创作内容”。完整剧本**不能自动变成可运行的文本节点**。用户通过画布已有的“添加文本节点 / 添加视频节点 / 连接参考照片 / 运行此节点 / 加入时间线”逐镜头制作。每个视频节点仍由用户单独启动和审批。项目里已有节点、照片、时间线都不被新原文覆盖。桌面端已有本地整集导出；网页版目前“导出整集”不可用，须另立服务端整集渲染与下载需求，不能把本版画布交接验收写成网页成片导出通过。

### 项目库与全局导航

项目库继续保留“新建空白项目”的入口，用于不从首页创意开始的人；这条旧路径不强制填写创作原文。左侧首页、创作、画布、结果、资产五个导航保持可切换；无项目时各显示自己的空状态。切换导航不会清除未提交输入，也不会触发生成。

## 3. Agent 功能边界与接口

### 必做能力

1. 接收账号内 1–200 字关键词/一句话；只在 H-1 被点击时调用文字模型。默认支持现有可配置的 OpenAI 兼容 Chat Completions 接口；现有 `agents/cursor` 提供方若启用，输出同一业务格式，前端不显示提供方选择。
2. 为**同一个 5–10 秒镜头**输出恰好三版明显不同的创意方向；每版含 `id`、`title`（≤50 字）、`description`（≤160 字）、`prompt`（≤2000 字）。三版提示词不能完全相同、不能凭空断言参考照片的具体内容、不能把 3 版写成连续 3 镜头剧本。
3. 保存请求意图、状态和模型返回。请求 ID 在模型调用前持久化；同账号同 ID 同输入重放只返回原草案，不二次调用。跨账号访问返回不可见；同 ID 不同输入返回冲突。
4. 支持 `pending/ready/failed/unknown`；长时间等待和断线后查询原记录。`unknown` 不自动重发模型请求，只允许用户明确另起一轮。错误保留真实状态，不用静态模板伪装成功。
5. 保存用户选中的版本与编辑后文本，供 S1 创建项目使用；原始关键词与模型原版内容保留。Agent 生成三版不得创建项目、视频 `agent_run`、视频 `operation`，不得扣视频演示额度。
6. 沿用账号/平台限流和服务端凭证。当前默认阈值是账号 20 次/24 小时、平台 200 次/24 小时，配置可调；页面显示服务端返回的限流提示，不暴露密钥或原始供应商错误。

### 明确不做

完整剧本自动拆镜、自动给每个节点写提示词、自动批量调用视频模型、自动加入时间线；这些属于后续 Agent 能力，不能在当前按钮文案中暗示已经提供。

### 现有与新增接口约定

| 接口 | 当前/目标 | 要求 |
| --- | --- | --- |
| `POST /prompt-ideas` | 现有，复用 | `{clientRequestId,input}`；返回 `ideaSet`，持久化先于模型调用。 |
| `GET /prompt-ideas`、`GET /prompt-ideas/:id` | 现有，复用 | 列表/查询原请求；账号隔离。 |
| `POST /prompt-ideas/:id/selection` | 现有，复用 | `{variantId,editedPrompt}`；服务端校验本账号、本轮、1–2000 字。 |
| `POST /projects` | 现有接口需扩展 | 可选 `initialBrief`；新首页路径必须携带，项目库空白路径可以不携带。项目与首条原文同一次持久提交。相同项目 ID 同内容重放返回同一项目或可由 GET 找回；不同内容冲突。 |
| `GET /projects/:id` | 现有接口需扩展响应 | 返回原文列表及修订信息；只对项目所属账号可见。 |
| `POST /projects/:id/commands` | 现有接口需扩展 `brief` 资源 | 向已有项目追加/编辑原文，使用命令 ID 去重与资源修订冲突检测；不能覆盖其他原文。 |
| `POST /projects/:id/runs`、`POST /runs/:id/approve` | 现有，复用 | 只有 G1 检查计划、G2 审批进入；首页、H1、S1、C1 打开时不调用。 |

**建议的共享数据契约（前后端按此命名）**：

```ts
type CreationBrief = {
  id: string;                         // 客户端生成，命令重试保持不变
  source: "manual" | "agent";
  originalText: string;               // 首页输入原文，1–10000 字
  finalText: string;                  // 手写原文或选定并编辑的提示词，1–10000 字
  ideaSetId?: string;                 // source=agent 时必填，且属于当前账号
  variantId?: string;                 // source=agent 时必填，且属于 ideaSetId
  createdAt: number;
  updatedAt: number;
};
```

云端项目在文档里增加 `briefs: CreationBrief[]`，旧项目迁移为 `[]`；桌面本地项目在 `ProjectManifestV2.extensions.creationBriefs` 保存同构数据。`source=agent` 首次保存时 `finalText` 必须是已保存的选中编辑文本；进入项目后的后续编辑可修改 `finalText`，但不改 `originalText` 或来源 ID。`source=manual` 不触发模型请求。服务端验证内容长度、账号所有权、Agent 草案归属、`id` 与命令重放；桌面同步将 brief 作为独立资源处理，冲突时让用户选择，不能静默用云端/本地覆盖。项目归属/方式选择属于 UI 状态，`CreationBrief` 不代表视频任务。

## 4. 前端开发拆分

| 优先级 | 任务 | 涉及代码与验收点 |
| --- | --- | --- |
| P0-F1 | 统一首页输入组件 | `packages/components/ProjectHome`、`packages/ui-web/PromptIdeas`：去除首页第二个“开始新项目”主入口；一个输入区承载两动作；1280×720 首屏可见，窄屏不横向溢出。 |
| P0-F2 | 两条路径状态机 | 网页 `apps/web/src/App.tsx`、桌面 `apps/desktop/src/App.tsx`：草案按账号/本机隔离；Agent 选中/编辑和手写内容都进入 S1；返回与切页不丢内容；错误/加载/待确认显示准确。 |
| P0-F3 | 作品设置页 S1 | 新建/已有项目、2 种制作方式、项目名/目标分集、明确提交；新项目同 ID 恢复，已有项目添加原文；长剧本不误入单镜头。 |
| P0-F4 | 单镜头与画布交接 | 直生复用现有 G1/G2；画布增加非执行的“创作原文”面板；不得把整篇剧本写入可运行文本节点。 |
| P0-F5 | 桌面本地与云状态 | 本地创建、保存、重开后原文可见；未登录 Agent 禁用，手写可用；登录关联后云端一致，冲突按现有交互显式处理。 |
| P1-F6 | 可访问性与视觉复核 | 主输入标签、卡片 `aria-pressed`、焦点、禁用原因、键盘操作、深浅色；真实网页及桌面截图复核首屏。 |

## 5. 后端与共享模型开发拆分

| 优先级 | 任务 | 验收点 |
| --- | --- | --- |
| P0-B1 | 共享 `CreationBrief` 契约和迁移 | 旧项目可读取；云端、桌面本地、DSL/同步投影不丢 `briefs`；字段校验与字符数统一。 |
| P0-B2 | 原文随新项目原子创建 | `POST /projects` 同时持久化标题、首集、首条原文；重放/响应丢失不会造第二个项目或漏原文。 |
| P0-B3 | 已有项目追加与编辑 | `brief` 独立资源、命令 ID 去重、修订冲突返回当前快照；跨账号不可读写；历史原文不被覆盖。 |
| P0-B4 | 桌面同步原文 | 本地变更 push，云端变更 pull；同条原文两端编辑须提示冲突，不静默合并；未登录项目只留本机。 |
| P0-B5 | Agent 业务守卫 | 沿用既有文字模型接口，补测三版差异、归属、错误/限流、断线重放；确保 H1 请求不会创建视频任务或扣视频额度。 |
| P1-B6 | 可观测性 | 记录请求 ID、状态、耗时和成功/失败码；日志不记录全文剧本、密钥和照片地址。 |

**依赖顺序**：B1 → B2/B3 → F3/F4；F1/F2 可与 B1 并行；B4 在 B1/B3 后；F5 在 B4 后。前后端以本节数据契约和上节接口表对齐，不允许前端先用 `sessionStorage` 冒充项目原文的长期保存。

## 6. 测试与验收用例

## 7. 本版边界与后续

本版解决“有想法/没想法都能进入作品”的入口与保存闭环。后续再评估：Agent 按长剧本拆分镜头、批量生成前逐镜头成本确认、自动把结果编入时间线、跨设备协同编辑。后续功能需另立需求与验收，不由本版按钮隐含承诺。
