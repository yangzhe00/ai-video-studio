# 整集剪辑 v2：AI 视频编辑与时间线重设计

日期：2026-11-02；状态：产品交付稿。交互原型：`design/prototypes/episode-ai-video-edit-v2/index.html`。本稿在既有“整集剪辑”上增量设计，Web 与 macOS 桌面共用交互；移动端本轮只要能读取新版本，不做标注或多轨编辑。

## 1. 用户问题、取舍与目标

用户在整集时间线看到某个镜头不满意时，目前只能回到其他位置处理，难以指明“改画面里的这一处”。用户提供的参考图包含视频预览、框选、文字标注和自然语言编辑框。我们将它融入整集剪辑：**先选镜头，停在要改的帧，标注画面并写要求，明确费用后提交，预览新旧视频，再决定是否替换**。原片、配音、音乐及上一次成片一直可找回。

现有时间线深色大色块、镜头辨认度弱，时间尺只能点击跳转。v2 改成浅色分轨、镜头缩略帧、可见的播放头和可按住拖动的时间尺，同时保留多轨、缩放、音频裁剪与保存能力。

产品取舍：P0 只处理一个选中视觉片段；从“整集剪辑”进入，但一次 AI 请求不自动重生成整集。原因是对象标注只属于某一帧和源片段，整集生成会混淆影响范围，也使费用和替换结果难以确认。用户可逐镜头处理，再用现有整集预览与导出完成成片。P1 再考虑跨镜头一致性编辑。此取舍是本产品方案，架构需评估供应商是否真实支持视频局部编辑；不能用普通提示词重生成假装“精准修改”。

## 2. 页面结构与入口

| 区域 | 控件 | 点击／拖动后行为 |
| --- | --- | --- |
| 整集页首 | `✦ AI 视频编辑` | 对当前选中的镜头打开编辑工作台；未选中时取播放头所在镜头；空分集时禁用并提示先加入视频。 |
| 画面轨 | 镜头缩略帧块 | 单击选中并将播放头移至镜头起点；双击打开该镜头的 AI 编辑。原声、配音、音乐轨仍保留。 |
| 右侧属性 | `✦ AI 编辑这个镜头` | 与页首入口同一工作台；右侧同时显示镜头名、片段范围、当前版本。 |
| 中间播放器 | `播放／暂停`、拖动进度 | 连续播放整集或定位到某帧；打开 AI 编辑时暂停，并以当前帧为默认标注帧。 |
| 时间线工具 | `－`、`适配全片`、`＋` | 缩小、按可见宽度适配、放大；保持当前播放头时间和横向滚动位置合理可见。 |
| 时间尺 | 1 秒小刻度、5 秒主刻度、播放头 | 单击定位；按住左右拖动播放头，画面和时间读数连续更新；滚动容器边缘时可自动横移；Esc 取消拖动，键盘左右键每次 0.1 秒。拖动时间尺不修改音视频片段，也不触发保存。 |

时间线视觉规范：页首和素材／属性区保持现有产品浅色体系；时间线背景用中性灰，轨道交替轻微区分；画面轨给每段显示视频帧缩略图、镜头序号与标题；原声、配音、音乐使用不同但低饱和的底色，音轨继续显示真实波形；播放头用单一暖色高对比细线。时间尺与左侧轨名固定，横向只滚动内容。1440×900 显示完整工作台；900px 宽不能裁掉“AI 视频编辑”、播放头或应用结果按钮，必要时轨道横向滚动。

## 3. AI 视频编辑工作台：控件、状态与交互

入口显示在整集剪辑内，形式为遮罩工作台。背景时间线保持原草稿；关闭可返回原位置。工作台主区左边是视频画面，右边是编辑范围和规则，底部是文字要求与提交。

| 控件 | 行为与验收口径 |
| --- | --- |
| 顶部镜头名／关闭 `✕` | 明示镜头序号、绝对起止时间、源版本。关闭时若有未提交文字或标注，保留草稿并提示；重新打开能继续。已提交任务关闭后在任务记录可查询原任务。 |
| 视频帧与`编辑时刻`滑块 | 默认使用当前暂停帧；可在选中镜头内拖动到其他帧。换帧时须提示当前标注只属于旧帧，用户选择保留旧帧或清空重标，不能静默丢失。截图显示该帧的时间戳。 |
| `框选` | 按下拖出矩形，显示描边；可重新选择、删除。坐标按画面内容归一化保存，避开播放器黑边，横竖屏及缩放后保持位置。框选说明“重点修改区域”，不是自动生成像素级精确蒙版的承诺。 |
| `文字`、`标点` | 单击画面放文字说明或定位点；文字不能为空，上限 60 字；标点可关联到底部文字要求。P0 必备，参考图中的画笔、箭头、橡皮擦列入 P1。 |
| `撤销标注`、`清空` | 仅作用于当前标注帧，不撤销整集时间线编辑。清空后仍保留底部文字。 |
| `＋ 添加参考图片` | 可选 PNG/JPEG/WebP，单张 ≤10 MB；缩略名称可见，用户可移除。源视频与当前标注帧始终随请求提交，不依赖用户额外上传图片。 |
| 底部输入框 `告诉 Agent 你想怎么改` | 最多 500 字；例：“把框选的小狗改成戴厨师帽，保持镜头运动和背景不变”。提交前要求具体文字 + 至少一个框／文字／点或参考图片；避免空请求。 |
| `查看费用并提交` | 先请求服务端报价/额度说明，展示本次源片段、标注帧、文字要求、预计成本和计费规则。用户点二次确认才创建模型任务；无法报价、余额不足或供应商不支持当前请求时阻止提交并说明原因。 |
| 任务状态 | `待提交／处理中／成功／失败／取消`；显示任务 ID、提交时间、原输入摘要、进度或可恢复说明。断线/刷新重新查询原任务，不能在状态未知时自动创建第二个计费任务。失败保留原片和标注草稿。 |
| 结果区 | 两列“原片 V1 / AI 新版本 V2”，都是真实可播放视频，显示时长和版本。按钮 `保留原片`、`仅保存为候选版本`、`替换选中镜头`。只有点替换才以新素材写入分集新修订；原视频及旧成片保留。 |

### 输出与时间线规则

1. P0 编辑对象是选中视觉片段实际使用的源视频和其已裁剪范围。提交时冻结项目、分集资源修订、视觉片段 ID、源视频资产 ID、源片段入/出点、标注帧绝对时间、原始帧图、带标注帧图、结构化标注和文字要求。后端按账号隔离，拒绝引用他人资产。客户端不信任本地生成的帧图作为唯一源；后端从源视频抽取相同时间帧并合成标注图，避免跨域画布和伪造输入。
2. Agent 解析用户要求并调用**经架构验证支持此类视频编辑的供应商能力**，以原视频 + 标注帧/参考图 + 文字要求生成新片段。供应商没有对应能力时返回明确“不支持/未配置”，不交付随机视频或只改提示词的假成功。模型实际能否准确修改指定区域由真实供应商验收，不以模拟结果通过。
3. 新片段为独立资产和版本，不能覆写原视频。默认只影响选中镜头；镜头 ID 和音频片段 ID 保持稳定。申请替换时核对最新分集修订，冲突时展示“云端已更新，查看差异／保留候选”，不能静默覆盖。相同时长可直接替换；较长结果须明确裁到原片段长度再替换，较短结果不自动补帧，先要求重做或另存候选。替换后本集精准预览失效，须重新预览再导出。
4. AI 结果的音轨：默认保留本集原声/配音/音乐时间线；若新片本身有声音，应用前提示“新视频有原声，是否保持原声/静音新片原声”，防止叠音。历史单镜头已混音视频同样按原声处理。画面替换不自动移动旁白或音乐；若时长变化则本轮不直接应用。
5. 框选和标注不烧录进新视频，也不会作为公开可见贴纸；只是给 Agent 的编辑条件。图片与文字作为任务输入按现有数据保留/删除政策管理，日志不能记录私密图片内容、令牌或供应商密钥。

## 4. 前后端开发边界

**前端（共享 Web/桌面组件）**：重排时间线 DOM/CSS，真缩略帧及真实波形，Pointer Events 时间尺拖动、键盘、横向滚动和缩放；AI 编辑工作台的暂停帧、归一化标注、参考图片、提示词、报价确认、任务轮询/恢复、双视频对比、应用前影响提示和冲突处理。保持既有时间线所有音轨编辑、保存、精准预览和导出能力。不能把原型静态图、模拟等待或假结果当生产逻辑。

**后端/架构**：先给出供应商能力与费用证据、输入格式限制、片长/尺寸限制；确定真实可用的 provider adapter。API 至少覆盖 `prepare/quote`、`submit`、`get operation`、`apply result`，请求必须包含稳定 `clientRequestId`、`expectedEpisodeRevision`、`visualClipId`，提交与结果应用均幂等。服务端抽帧/合成标注图、校验素材和文件、冻结快照、持久化输入/任务/结果版本、恢复状态、计费边界、鉴权与清理。沿用现有操作状态模型和对象存储规范，不凭前端假设确定接口路径；共享契约由后端与前端先对齐。

**相互依赖**：前端可以先实现时间线外观与本地标注，但“真实 AI 编辑成功”依赖后端 provider、报价和任务 API。若供应商不能支持，用户仍可用整集时间线；AI 入口显示真实阻塞原因，不悄悄调用其他生成链路。

## 5. 优先级与非目标

- P0：时间尺指针拖动与键盘定位、时间线视觉重排、镜头缩略图、选镜头入口、单帧矩形/文字/点标注、文本+参考图、真实报价确认、真实任务恢复、新旧视频对比、非破坏式替换、全链路 Web/桌面验收。
- P1：画笔、箭头、橡皮擦，多帧标注，多个候选并排比选，跨镜头主体一致性，手机端触摸标注。P1 不阻塞 P0。
- 本轮不做任意区域的帧级修复承诺、整集一键重拍、自动替换、无限次数免费重试或实时流式生成。

## 6. 可量化验收

| 编号 | 验收标准 |
| --- | --- |
| A01 | 1440×900 和 900px Web/原生：时间尺可按住拖动 0→7.3→12.8 秒，画面与读数实时对应；松手不发生分集写请求。单击和键盘 ±0.1 秒可用；滚动和缩放后仍准确。 |
| A02 | 三段 5 秒镜头、两段配音、一段音乐及真实波形都显示；改样式后拖动/裁剪音轨、保存、精准预览/导出不回归。 |
| A03 | 选第 2 镜头，在 7.3 秒框选区域、放文字、输入要求、可选加一张参考图；确认页显示实际同一帧和费用；取消不创建模型任务，确认只创建一条。 |
| A04 | 真实模型任务刷新和断线后查询同一 `clientRequestId`；成功时原/新视频分别能播放，用户仅保存候选时分集无变化，替换后分集修订 +1 且源视频/旧成片可访问。 |
| A05 | 同账号另一端改变分集后，旧结果应用返回冲突；跨账号素材/任务不可见；无报价/无模型/余额不足/供应商失败均显示可恢复说明，无假结果和重复扣费。 |
| A06 | 测试交付 Web 与原生真实页面截图、真实任务状态、双视频对比、应用前后时间线、MP4/媒体探测和供应商成功或真实阻塞证据；原型或 mock 截图不能算通过。 |

补充需求：文字生成旁白进入配音轨，以及当前供应商配置阻塞，见 `docs/product/2026-11-02-episode-tts-unblock.md`。

## 7. 原型与证据边界

HTML 原型可点击选镜头、拖时间尺、缩放、框选、放文字和点、提交并查看模拟结果。示例画面、波形、费用确认、等待和结果都是演示；它没有上传文件、调用 Agent、保存云端或生成 MP4。真实能力需按 A01–A06 验收。
