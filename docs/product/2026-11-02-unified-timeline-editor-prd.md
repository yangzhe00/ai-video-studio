# 整集可视化音视频时间线：需求与交互说明

日期：2026-11-02。状态：交付开发的产品方案。原型：../../design/prototypes/episode-timeline-editor/index.html。

## 1. 用户问题与目标

现有镜头“视频微调”里的配音长表单、网页“本集配音与导出”弹窗、桌面“整集配音”独立页把画面与音频分开。用户只能输入秒数后等待服务端合成，无法直观看到配音与镜头切点的关系；现有简单编辑器只呈现第一段配音，可能隐藏其他已保存音频。用户提出：直接在一条可视化时间线上拖动配音、对齐画面并实时检查整集效果，移除现有配音界面。

P0 目标：让第一次剪辑 15 秒、3 镜头短片的用户，从画布进入一个全屏编辑工作台，把已有录音或音乐放到正确时间，立即试听，再做精确合成预览与整集导出。保留原片、旧版本及所有历史音轨。

## 2. 范围与页面关系

- Web 与 macOS 桌面共用产品交互和时间线规则。移动端本轮只要求共享项目可读取，不交付触屏多轨剪辑。
- 画布负责镜头节点、参考照片与生成；点击“整集时间线”进入全屏“整集剪辑”。结果页的“加入时间线并配音”先加入选中的片段，再进入此页。项目与分集上下文明确显示在页首。
- 原“本集配音与导出”弹窗、桌面“整集配音”独立页和单镜头“视频微调”内的配音表单入口下线。单镜头裁剪、字幕、封面仍在原视频微调页；配音统一到整集时间线。若尚未加入分集，先由用户明确选择分集。
- 旧音频 API、渲染配方和历史数据不得因为前端入口下线而删除。旧单镜头已渲染进视频的配音作为该视频的原声播放；不得自动把同一语音再次铺入分集配音轨。界面提示“片段内已有声音，叠加新配音前可静音原声”。
- 现有 Agent 剪辑建议由旧分集配音页面移入新编辑页的“Agent 建议”抽屉；按最新分集版本显示差异并逐条确认，不自动付费或导出。

## 3. 页面结构与按钮

| 区域 | 控件 | 交互与结果 |
| --- | --- | --- |
| 页首 | 返回画布 | 保存成功则返回当前分集画布；保存中先等待；保存失败显示“保留本地草稿／重试保存／取消返回”，不能静默丢失。 |
| 页首 | 已保存／保存中／保存失败 | 每次拖放结束或字段提交后更新。拖动过程不发写请求；失败保留本地改动与重试入口。 |
| 页首 | 撤销、重做 | 撤销/重做位置、裁剪、音量、添加、删除与镜头原声设置；每次拖动松手只算一步。 |
| 页首 | Agent 建议 | 打开整集剪辑建议抽屉；旧功能迁移，生成和应用都校验最新分集版本。 |
| 页首 | 精准预览 | 对已保存的分集修订创建服务端合成预览，显示等待、可播放、失败和刷新恢复。新编辑使旧预览失效。 |
| 页首 | 导出成片 | 保存成功且当前修订的精准预览可播放后可用；新建独立 MP4，原片及旧成片保留。重复点击沿用原任务。 |
| 素材库 | 上传自己的录音、上传背景音乐 | 选择 MP3/WAV/M4A；服务端探测真实格式和时长。成功作为 voice/music 资产出现，不自动放入影片。 |
| 素材库 | 文字生成配音 | 输入文案、音色和语速；先查看费用说明，用户二次确认才提交。成功的 voice 资产出现后，由用户拖入。供应商未配置时显示原因和上传录音入口。 |
| 中间 | 播放／暂停、播放头 | 从当前时间播放整集，连续跨镜头，听见当前原声、配音与音乐；拖动播放头可定位。视频不存在或音频缓冲中均有明确状态。 |
| 时间线 | 画面轨、镜头原声、配音轨、音乐轨 | 同一横向时间尺。画面片段显示镜头名与切点；配音和音乐显示片段及波形；多段已有片段不得隐藏。音乐、配音可重叠，并显示重叠关系。 |
| 时间线 | 拖入、移动、拖边裁剪、缩放 | 从素材库拖入对应轨；松手后形成草稿。拖片段移动位置，拖两端改变入/出点；靠近 0 秒、镜头切点和播放头时吸附，精度 0.1 秒。键盘左右箭头每次移动 0.1 秒。 |
| 右侧 | 起点、录音入点、录音出点、音量、跟随方式、移除 | 选中片段后精确修改。移除只移除时间线引用，不删除素材。新语音默认绑定所对齐镜头，跨镜头旁白可选“固定在整集时间”。 |

## 4. 时间与边界规则

1. 时间线以分集 0 秒为原点。画面片段使用既有顺序及裁剪长度累加得到切点；音频起点用分集绝对时间保存，入点/出点引用原始素材范围。所有字段使用整数毫秒存储、0.1 秒界面精度。
2. 拖动音频到分集结尾外时显示超出部分，明确提供“裁到结尾并加入／取消”。不修改原始素材。长度小于 0.3 秒的截取拒绝保存。
3. 新配音默认跟随其落点所在镜头；镜头排序时相对镜头的偏移保持。跨镜头旁白可改为按整集绝对时间定位。旧数据没有锚点时保留原绝对时间，不推测用户意图；排序后提示核对。后端先确定稳定片段 ID 与锚点的兼容格式，再让前端依契约开发。
4. 镜头原声在时间线上单独可见、可静音和调音量；它仍引用视频自带音轨，不复制为第二个音频文件。多段语音和音乐素材都应显示，不能只暴露第一条。
5. 即时试听读取当前未保存草稿，不为每次拖动创建服务器 MP4；服务器“精准预览”和正式导出读取已保存的相同修订与配方。浏览器／桌面无法即时试听时显示原因，并可使用精准预览，不假称“实时”。
6. 同一账号在另一端编辑造成版本冲突时，保留本端草稿并展示“查看云端版本／重试合并”，不能静默覆盖。切换分集、退出登录和刷新时处理未保存改动。

## 5. 非目标

本轮不开发变速、转场、自动对口型、AI 自动生成配乐、复杂音频特效或手机端多轨编辑。文字配音真实供应商调用的凭据与费用门禁仍遵守原有任务规则，不能因为 UI 重构跳过。

## 6. 验收目标

- 15 秒、3 个 5 秒镜头，至少 2 段语音和 1 段音乐，其中一段语音跨镜头切点；用户能看见、移动、裁剪、试听并导出所有轨道。
- 已缓存素材：松手后视觉反馈目标 ≤100 毫秒；点击播放后目标 ≤1 秒开始试听；即时试听与最终 MP4 的音频起点差目标 ≤150 毫秒。均为内部验收目标，不作为已实现的宣传承诺。
- 精准预览与正式导出同修订、同时间与混音语义；输出文件实际有视频和 AAC 音轨。原始素材、旧编辑版和上一次成功成片保持可访问。
- 历史 5 秒和 10 秒镜头、旧分集多段 voice/music、旧单镜头已混音版本能读取和导出，且不能发生音频重复叠加或数据丢失。
- Web、桌面分别提交真实页面截图；测试报告区分代码测试、隔离 API、真实 GUI、真实供应商与公网发布，不将其中一种结果代替另一种。

## 7. 交付说明

原型是独立 HTML，含拖动、裁剪、精确修改、空状态、断网保存、费用说明及导出提示的交互演示。演示画面和波形均为示意，不产生真实音频、费用、云端写入或 MP4。开发按本需求实现，不复制原型的模拟数据逻辑。
