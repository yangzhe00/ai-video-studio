# 产品需求规格 PRD（阶段三产出）

> 上游依据：`01-业务界定.md`、`02-产品定义.md`
> 业务规则数值类参数一律标"⏳ 待业务确认"，本团不编造数值。
> 九项结构：编号 / 名称 / 描述 / 业务规则 / 前置条件 / 主流程 / 异常与边界 / 验收标准 / 追溯

## 1. 核心业务对象与状态机

### 1.1 生成任务状态机（全站统一）

```
草稿 → 已提交 → 排队中 → 生成中 → 成功 / 失败
                                  失败 → (可重试) 已提交
成功 → 已使用(进入合成) → 已合成 → 已导出
草稿 → 已作废
```

- **异步长时任务**：生图、生视频、TTS、合成均为异步任务，前端轮询或推送进度
- **失败分类枚举**：参数错误 / 额度不足 / 供应商故障 / 内容审核不通过 / 超时（具体枚举与重试策略 ⚙️ 待研发确认）
- **超时处理**：生成中超过阈值（时长 ⏳ 待业务确认）标记失败并允许重试

### 1.2 权限矩阵（一期最简）

| 操作 | 已登录用户 | 未登录 |
|---|---|---|
| 选题/讲稿/生图/生视频/合成/下载 | ✅ 仅本人数据 | ❌ 跳登录页 |
| 查看他人任务/成片 | ❌ 不可见 | — |
| API Key/模板配置 | ❌（后端预置，无界面）✅ 已确认 | — |

数据范围：用户仅可见自己的素材、任务与成片（行级隔离，⚙️ 待研发确认实现方式）。

## 2. 功能需求

### A 域：选题与脚本辅助

**FR-A-01 选题灵感生成**
- 描述：用户输入创作领域/关键词/参考方向，系统调用 LLM 生成选题列表，每条含标题与内容角度
- 业务规则：一次生成条数为配置项（数值 ⏳ 待业务确认）；同一请求防重复点击
- 前置条件：已登录；LLM 服务可用
- 主流程：输入关键词 → 点击生成 → 展示选题卡片列表 → 可"选为我的选题"
- 异常与边界：LLM 超时/失败提示可重试；输入为空禁用按钮；生成结果敏感内容过滤 ⚙️ 待研发确认
- 验收标准：输入关键词后 30 秒内（时长 ⏳）返回选题列表；每条选题含标题+角度；失败有明确提示与重试入口
- 追溯：SC-01-01

**FR-A-02 讲稿生成与编辑**
- 描述：基于选定选题生成竖屏短视频口播讲稿，按段落组织，用户可逐段编辑
- 业务规则：讲稿长度按目标视频时长反推（时长参数 ⏳ 待业务确认）；段落与后续分镜一一对应
- 主流程：选选题 → 生成讲稿 → 分段展示 → 编辑保存
- 异常与边界：生成失败保留上次内容；编辑中离开提示保存
- 验收标准：讲稿按段落展示且可编辑；保存后数据持久；重生成有确认提示防止覆盖误操作
- 追溯：SC-01-01

**FR-A-03 分镜提示词生成**
- 描述：将讲稿各段落自动转化为图生视频的画面提示词，用户可修改
- 主流程：讲稿确认 → 一键生成分镜提示词 → 逐段预览编辑 → 进入生视频流程
- 异常与边界：段落过长时拆分策略 ⚙️ 待研发确认
- 验收标准：每段落至少对应一条提示词；可直接带入 FR-B-03
- 追溯：SC-01-01 → SC-01-02

**FR-A-04 草稿收藏**
- 描述：选题/讲稿可保存为草稿，随时恢复继续创作
- 验收标准：草稿列表可见、可删除、可恢复
- 追溯：SC-01-01

### B 域：生图与生视频

**FR-B-01 站内 AI 生图**（✅ 已确认纳入）
- 描述：输入画面描述调用生图 API 生成图片素材，存入素材库
- 业务规则：分辨率/张数按成片规格 9:16 预设（具体参数 ⏳ 待业务确认）
- 异常与边界：生成失败分类提示；额度不足预警（引用 FR-E-03）
- 验收标准：生成的图自动入素材库并标注来源；失败可重试
- 追溯：SC-01-02

**FR-B-02 素材上传**
- 描述：支持批量上传本地图（jpg/png/webp），进入素材库
- 业务规则：单文件大小上限、总容量 ⏳ 待业务确认（数值不给结构）
- 异常与边界：格式不支持明确提示；上传中断可续传 ⚙️ 待研发确认
- 验收标准：上传成功入素材库；不支持的格式被拦截并提示
- 追溯：SC-01-02

**FR-B-03 生视频任务提交**
- 描述：逐段关联「图片 + 提示词」，批量提交视频生成任务（可灵/即梦）
- 业务规则：任务提交前校验额度余额；同一素材可重复用于不同任务
- 主流程：选片段→关联图+提示词→提交→任务进入排队
- 异常与边界：额度不足阻止提交并提示余额；供应商不可用提示稍后重试
- 验收标准：提交后任务中心可见状态流转；至少两个供应商可选（多供应商 ⚙️ 待研发确认）
- 追溯：SC-01-02

**FR-B-04 片段管理**
- 描述：生成结果预览、删除、重新生成（保留原参数）
- 验收标准：预览流畅；重新生成创建新任务不影响旧结果
- 追溯：SC-01-02

### C 域：模板合成

**FR-C-01 模板选择**
- 描述：一期内置「简约生活风」模板（数量 ⏳ 待业务确认），含片头/片尾/字幕样式/背景音乐
- 业务规则：模板后端预置，一期无模板编辑界面 🚫（自定义模板二期）
- 验收标准：合成前必须选定模板；模板预览可见
- 追溯：SC-01-03

**FR-C-02 AI 配音**
- 描述：讲稿分段转 TTS 语音，音色可选（音色库 ⚙️ 待研发确认供应商）
- 异常与边界：TTS 失败可重试；支持试听后再确认
- 验收标准：每段音频与段落对应；试听可用
- 追溯：SC-01-03

**FR-C-03 自动字幕**
- 描述：按配音逐句生成字幕，样式随所选模板
- 异常与边界：对齐偏差的处理策略 ⚙️ 待研发确认；支持手动改字幕文本
- 验收标准：字幕与语音句级对应；可在合成前修改文字
- 追溯：SC-01-03

**FR-C-04 成片合成**
- 描述：片段+配音+字幕+模板在服务端拼装为 9:16 mp4 成片（技术方案 ffmpeg ⚙️ 待研发确认）
- 主流程：确认要素齐全 → 提交合成任务 → 生成中 → 成片入库
- 异常与边界：要素缺失（缺片段/缺配音）明确列出缺什么，禁止提交；合成失败可重试
- 验收标准：成片规格 9:16、声画对齐、字幕可读；失败任务可重试
- 追溯：SC-01-03

### D 域：导出

**FR-D-01 成片预览与下载**
- 验收标准：可在线预览；下载为 mp4；文件名含选题标题与日期
- 追溯：SC-01-04

**FR-D-02 版本历史**
- 描述：同一选题多次合成结果保留，可对比、可删除
- 业务规则：历史保留时长/数量 ⏳ 待业务确认
- 追溯：SC-01-04

### E 域：任务与额度

**FR-E-01 任务中心**
- 描述：全部异步任务（生图/生视频/TTS/合成）统一看板，含状态、耗时、所属选题
- 验收标准：状态与 1.1 状态机一致；可按类型/状态筛选
- 追溯：SC-01-06、SC-01-07

**FR-E-02 失败分类与重试**
- 描述：失败任务按 1.1 枚举分类展示原因；参数错误需修改后才可重试
- 验收标准：每条失败任务可见失败原因分类；审核不通过类不自动重试
- 追溯：SC-01-06

**FR-E-03 用量记录与额度预警**
- 描述：按任务记录 API 消耗；额度低于阈值（阈值 ⏳ 待业务确认）时预警
- 验收标准：每任务可查消耗；预警在任务提交前拦截提示
- 追溯：SC-01-07

**FR-E-04 登录**
- 描述：邮箱/手机号最简登录，不做注册审核与角色权限
- 异常与边界：登录失败提示；会话过期跳登录并保留当前页
- 验收标准：未登录访问任意功能页跳转登录；登录后仅见本人数据
- 追溯：Gate 2 公共支撑

## 3. 异常与边界八项覆盖自查（Gate 3）

| 项 | 覆盖需求 |
|---|---|
| 网络中断 | FR-B-02 续传、任务中心可刷新状态 |
| 供应商故障 | FR-E-02 分类、FR-B-03 多供应商降级 |
| 额度不足 | FR-E-03 预警、FR-B-03 提交拦截 |
| 内容审核不通过 | FR-E-02 不自动重试、明确提示 |
| 并发/重复提交 | FR-A-01 防重、任务幂等 ⚙️ |
| 数据丢失 | FR-A-02 离开提示保存、FR-D-02 版本历史 |
| 长时等待 | 全站异步任务+进度展示 |
| 空状态 | 素材库/草稿/任务中心空态引导 |

## 4. 外部依赖降级登记（Gate 3）

| 依赖 | 阻断 | 降级方式 | 状态 |
|---|---|---|---|
| 视频生成 API | 是 | 排队重试/切换供应商 | ⚙️ 待研发确认 |
| 生图 API | 否（可上传兜底） | 提示改用上传 | ✅ |
| LLM API | 否（A 域不可用不影响 B/C/D） | 用户自写讲稿直接进入 B 域 | ✅ |
| TTS API | 是（影响配音） | 暂不可用提示（一期无自录上传兜底，二期再议 🚫） | ✅ 已声明 |
| 对象存储 | 是 | 暂不可用，上传/下载停用 | ⚙️ 待研发确认 |

## 5. 需求追溯链（Gate 3 自查）

业务目标（解决选题难+制作繁）→ SC-01-01~07 → 能力域 A~E → FR-A-01~E-04 → 各验收标准 ✅ 无孤立需求、无断链。
