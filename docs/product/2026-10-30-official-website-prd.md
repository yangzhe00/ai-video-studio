## 1. 用户、目标与范围

**访客**：第一次接触产品、需要确认它是否适合自己并想体验的人；准备在 Mac 上安装桌面版的人。**主要任务**：快速看懂创作闭环，选择“网页版创作”或“下载 macOS 测试版”，成功打开对应产品。

本轮交付静态官网、创作应用入口迁移、版本化 DMG 下载、安装指引和上线验收。官网不采集邮箱、不在营销页申请权限、不展示价格承诺。真实生成费用、登录、项目数据沿用现有应用和 API。移动端官网可阅读并进入网页版，桌面 DMG 只面向 Apple Silicon Mac。

成功标准：首屏 1280×720 中看见产品定位及两个主行动；390×844 无横向滚动且可完成导航；直接打开/刷新 `/studio/` 正常；公开下载返回 DMG 而不是 SPA HTML，下载字节 SHA-256 与发布清单一致；包内 App 通过结构/签名检查并在目标 Mac 安装、启动；线上根页、API 和旧项目数据在发布后可用。

## 3. 页面结构与按钮清单

官网是一页式介绍，`/studio/` 是现有创作应用，`/downloads/` 仅提供文件。页面段落按“认识 → 了解流程 → 查看产品 → 选择入口 → 安装”排序。按钮数为正常桌面态；导航折叠到手机时项目数不变。

### W0 顶部导航与首屏

顶部固定 1 个 Logo（回到顶部）、4 个锚点链接：**产品能力、创作流程、桌面版、常见问题**，1 个主按钮 **进入网页版**。手机为 1 个“打开菜单”按钮，点击展开同样 4 个链接和“进入网页版”；点击链接、按 Escape 或点遮罩后收起，焦点回到菜单按钮。

首屏标题：“写下想法或剧本。从一个镜头开始，做成自己的故事。”副标题：“把自己的内容保存到项目；做一个镜头，或进入分集画布手动安排多个镜头。生成前，再检查照片和镜头计划。”两枚按钮：**开始网页版创作**（同源 `/studio/`）和 **下载 macOS 测试版**（滚动到 `#download`，因为用户需先看到平台与安装说明）。右侧用自有分镜图形演示原文→手动安排镜头→分集画布，不是可提交的生成表单。点击两个按钮不自动创建账号、项目或视频任务。首屏次级说明为“Agent 三版镜头方向即将开放”。

### W1 创作流程

按顺序展示 3 步，使用简短实际操作文案：**写下想法**（一句话或完整剧本）、**保存并整理内容**（选项目，保留原文并可修改最终内容）、**决定如何成片**（单镜头或分集画布）。每步至多一张真实界面图，图可点击放大；放大层有关闭按钮、Esc 关闭、焦点限制与图片说明。此区有 1 个按钮 **去网页版试一试**，去 `/studio/`。

### W2 产品能力

展示四块不同信息而非四张等宽宣传卡：① 自写想法或剧本直接开始；② 参考照片与生成前确认；③ 分集画布与时间线；④ 原文保留与任务进度。每块有一行“你可以怎么做”和一张已验证的 UI 局部截图。① 可在正文末尾说明“Agent 三版镜头方向即将开放”，不得写成已可用。网页端不显示“导出整集成功”的画面；桌面本地导出标记平台范围。此区不增加付费按钮。

### W3 网页与桌面选择

两栏比较：

| 网页版 | macOS 桌面测试版 |
| --- | --- |
| 无需安装，登录后使用云端项目；适合随时接着创作与查看任务。 | 本地管理素材与项目，适合在 Mac 上编排和剪辑。当前仅 Apple Silicon。 |
| 按钮 **进入网页版** → `/studio/`。 | 按钮 **查看下载与安装** → `#download`。 |

“网页与桌面共享账号”不能写成“桌面未登录项目自动同步”。在比较块下方写清：“桌面本地项目需登录并关联云端后才可在网页版找到。”

### W4 下载区

下载卡展示：`AI Video Studio`、明确的 **macOS Apple Silicon 测试版** 标记、版本号、发布日期、文件大小、SHA-256 全值、状态“可下载/暂不可用”。有 3 个交互：**下载 DMG**、**复制 SHA-256**、**查看安装说明**。

- **下载 DMG**：指向不可变的 `/downloads/AI-Video-Studio-<version>-macos-arm64.dmg`。仅当该版本已通过打包门禁且文件在服务器上可访问时启用。浏览器获得真实文件下载，不在新标签显示 HTML。重复点击允许重复下载，不创建后台任务。
- **复制 SHA-256**：使用 Clipboard API；成功显示 3 秒“已复制”，拒绝权限时选中哈希文本并显示“可手动复制”。屏幕阅读器可读状态。
- **查看安装说明**：展开/收起说明。步骤为“下载并打开 DMG → 将 App 拖入 Applications → 从 Applications 启动”。若仍无 Developer ID，紧跟明确提示“这是未经 Apple 公证的测试版，macOS 可能拦截首次打开”，并链接 [Apple 官方的‘仍要打开’操作](https://support.apple.com/en-au/102445)。不教用户关闭 Gatekeeper 或删除隔离属性。

异常态：下载卡始终明确写“仅适用于 Apple Silicon Mac”，不根据浏览器 User-Agent 猜测 Mac 芯片；手机访问时加提示“请在 Apple Silicon Mac 上下载和安装”，仍可查看说明；文件未发布时下载按钮禁用并显示“下载准备中”，不可链接到本地 `target/` 或 404；下载失败时浏览器 HTTP 状态明确非 200，页面提供“重新下载”和问题反馈方式。支持断点续传由 Nginx `Range` 处理，不能把 `index.html` 当作下载兜底。

### W5 常见问题与页脚

5 个问题，逐项展开/收起：**需要先有照片吗？**、**Agent 三版镜头方向什么时候可用？**、**完整剧本能自动拆成多个镜头吗？**、**桌面项目会自动出现在网页版吗？**、**为什么 macOS 提示无法验证开发者？**。答案以本版实际能力为准；Q2 明确三版方向即将开放，当前先走“用我的内容开始”，将来即使开放也只提供文字提案，真正生成仍须再次确认；Q3 明确需手动拆镜；Q4 明确登录和关联条件；Q5 链接 Apple 官方说明。页脚含产品名、版本、**进入网页版**、**下载区**、以及可用的联系渠道（若没有已验证渠道则不显示虚构邮箱）。

## 6. 发布门禁与发布前阻塞记录

旧 DMG 的容器校验通过但包内 App 签名校验失败。已重新生成 ad-hoc 签名的 Apple Silicon DMG，容器和包内 App 严格签名校验通过；独立目录启动了 App 进程。**公网下载后的 macOS 隔离属性、Applications 安装和界面操作仍需测试完成，O06 不能据此判为全部通过。**当前没有 Apple 公证票据；只有明确标记测试版及可能的 Gatekeeper 操作，不能宣称“已公证”或“一键免提示安装”。参考 [Apple Developer ID](https://developer.apple.com/developer-id/) 与 [Apple 公证要求](https://developer.apple.com/documentation/security/notarizing-macos-software-before-distribution)。

发布前线上网页是旧 API/静态 release。用户选择最新版创作应用与官网一起上线，因此 PostgreSQL 迁移、API 兼容性、数据与素材备份、未完成任务恢复及公网回归是**本次发布前置**。真实视频服务仍须单独做付费调用前后的安全验收，不能由静态官网测试代替。实际执行结果见独立 QA 与发布记录。

线上部署记录曾观察到三版灵感返回 `provider_error`。因此 O04/O10 增加一条发布判定：官网以“三版镜头方向”为主卖点时，必须由测试账号在**公网最新版**实际拿到恰好三版，并确认仅调用文字服务、视频额度不变；若仍失败，先修复供应商接入，或将该文案改为“即将开放”并以手写路径作为首屏主入口。不能把本地模拟测试当线上通过。
