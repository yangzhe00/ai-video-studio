## 1. 产品定位一句话

面向个人创作者/知识博主的**视频成片工作台**：从选题灵感 → 图片素材 → 动态视频 → 模板合成 → 可发布成片，一站式完成竖屏短视频制作。

## 3. 三级功能结构（一期）

### A. 选题与脚本辅助（新增，直击核心痛点）
- A1 选题灵感：输入领域/关键词 → LLM 生成选题列表（含标题+内容角度）
- A2 讲稿生成：选定选题 → 生成适配竖屏短视频的口播讲稿（分段落，可编辑）
- A3 分镜提示词：将讲稿段落转化为图生视频的画面提示词（供 B 域使用）
- A4 灵感收藏：保存喜欢的选题/讲稿为草稿

### B. 图片生成视频
- B0 站内 AI 生图：输入描述生成图片素材（✅ 已确认纳入一期，复用即梦/可灵生图能力）
- B1 素材上传：批量上传图片（jpg/png/webp），支持 AI 生图入口（⏳ 是否站内生图待业务确认，可用外部生图后上传兜底）
- B2 提示词编辑：逐段关联图片与提示词，支持修改后重新生成
- B3 视频生成：调用视频生成 API（可灵/即梦），异步任务，显示排队/进度
- B4 片段管理：生成结果列表，预览、删除、重新生成

### C. 模板合成与配音字幕
- C1 模板库：竖屏 9:16 模板（片头/片尾/字幕样式/背景音乐），一期内置 2~3 套（数量 ⏳ 待业务确认）
- C2 AI 配音：讲稿分段转 TTS 语音，支持音色选择（具体音色库 ⚙️ 待研发确认 TTS 供应商）
- C3 自动字幕：语音与字幕逐句对齐，样式随模板
- C4 合成引擎：图片视频片段 + 配音 + 字幕 + 模板 → 拼装成片（⚙️ 待研发确认技术方案：ffmpeg 服务端合成）

### D. 成片导出
- D1 成片预览与下载（mp4，9:16）
- D2 版本记录：同一选题的多次生成结果保留历史

### E. 任务与额度管理
- E1 任务中心：全部生成任务的状态看板（排队/生成中/成功/失败），失败可重试
- E2 失败兜底：额度不足/供应商故障/审核不通过分类提示，额度耗尽前预警
- E3 用量记录：按任务记录消耗的 API 额度（对应外部依赖登记表）
- E4 登录：最简登录（邮箱/手机号），区分使用者，不做角色权限 🚫

### 公共支撑能力（Gate 2 检查项，不遗漏）
- 素材/成片存储与清理策略 ⚙️ 待研发确认（存储成本控制）
- 操作日志（谁在何时生成了什么）
- 配置管理：API Key、模板配置（⏳ 一期是否需要界面化配置，还是配置文件即可，待业务确认）

## 4. 一期业务闭环验证

**黄金任务流**：登录 → A1 选题 → A2 讲稿 → A3 提示词 → B1 上传图片 → B3 生成片段 → C1 选模板 → C2/C3 配音字幕 → C4 合成 → D1 下载成片

✅ 端到端可跑通，覆盖"不知道做什么"（A 域）与"制作繁琐"（B/C/D 域）两大痛点。
