# Agent Editing Design — 2026-10-30

## Intent

在已有视频和分集时间线之上，Agent 提供可理解的剪辑建议；用户预览、修改并确认后，现有编辑服务执行。Agent 不能直接运行 FFmpeg 命令，也不能自行提交付费视频或 TTS 任务。

## Scope

- 第一版建议只覆盖镜头裁剪、分集镜头排序、手工字幕草稿，以及从用户已确认的语音资产中选择配音及其时间/音量。用户可逐条接受或拒绝。
- Agent 输出必须经过共享 Zod Schema 校验，再由服务端校验项目/素材归属、时间边界、当前 revision 与可执行动作。无效建议显示原因，不自动应用。
- 建议集记录输入快照、模型/提示版本、状态、方案和目标资源 revision。预览是草稿，确认后才产生编辑命令和新 revision；渲染仍需独立的明确操作。
- 原片、旧编辑版本和用户已写的字幕/配音不能被静默覆盖；冲突时让用户重新查看差异。
- 智能换镜头、自动生成素材、对口型和自动发布不在本轮。

## Acceptance

- 有效建议可预览并逐条接受；非法时间、缺失素材、跨账号资产、旧 revision、空建议和模型失败都有可恢复反馈。
- 未点击确认时，项目版本、渲染 operation 和付费额度不变。重复确认同一建议集不会重复应用。
- Web/桌面保留人工编辑入口；Agent 失败时用户仍可继续手动剪辑。

## Approach chosen

Agent 只生成结构化建议，执行沿用已有共享命令、DSL 与版本化编辑服务。用户已在本会话批准上轮「建议 → 预览修改 → 确认执行」的开发优化计划。
