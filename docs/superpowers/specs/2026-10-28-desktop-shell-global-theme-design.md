# 桌面窗口栏与全局换肤设计

## 设计目标

桌面应用的最上方统一使用高 **48px** 的窗口栏，背景 **#E9EDEB**。窗口栏承载原生窗口控制区、首页与页面标签、全局换肤入口；生成、画布以及后续页面都从窗口栏下方开始。界面提供两套可一键切换的外观：当前选定的 **C4 奶油胶片**，以及用户图 1 的 **青蓝夜幕**。本阶段交付设计与样式规范，不改应用代码。

## Pen 交付

设计文件：`design/ai-video-studio-ui-options.pen`。

新增五个画板：

1. `全局主题 · 奶油胶片 / 生成`
2. `全局主题 · 奶油胶片 / 画布`
3. `全局主题 · 青蓝夜幕 / 生成`
4. `全局主题 · 青蓝夜幕 / 画布`
5. `全局换肤 · 样式设计板`

原有 A 与 C4 画板保留，方便逐项比较。四张新页面均为 1440×900，窗口栏占 y=0–48；奶油胶片沿用 C4 的暖色布局，青蓝夜幕沿用图 1 对应的深色青蓝布局。

## 桌面窗口栏

- 尺寸：宽度随窗口伸展，高度固定 48px；中性底色 `#E9EDEB`，不随主题变化。
- 左侧预留 macOS 原生窗口控制区。设计稿的三色圆点仅表达位置和占位；落地时由桌面壳提供窗口控制，不叠加第二组模拟按钮。
- 窗口栏中部为首页、项目或集的标签、当前页标签。当前页标签使用白色底，以便两种内容主题都容易辨认。
- 右侧放置单击换肤入口。奶油胶片显示“切换深色”，青蓝夜幕显示“切换暖色”；图标和文字共同表达目标主题。按钮具备悬停、键盘焦点和可读的辅助名称。
- 应用内容从 y=48 开始。页面内顶部工具栏属于内容区，不与窗口栏叠放。

## 换肤行为

一个全局 `skin` 状态只取 `cream-film` 或 `cyan-night`。单击窗口栏入口立即更新所有已打开的生成、画布、弹窗、状态与侧栏；切页、切集和重启后保留用户选择。切换仅改变视觉变量，保留输入文字、节点位置、选中状态、视频任务与时间线顺序，不发起生成或导出。

默认值为用户已选的 `cream-film`。主题选择属于应用偏好，不写入某一集的内容数据。若未来增加第三套外观，换肤入口再从直接切换改为菜单；当前两套保持一次点击即可完成。

## 原子化样式层级

这里的“原子化”指单一来源的基础样式量与语义映射，而非在每个页面复制一份 CSS 颜色表。

| 层级 | 内容 | 作用 |
| --- | --- | --- |
| 基础原子 | 颜色值、4px 间距基准、字号、字重、圆角、线宽 | 单点维护数值 |
| 语义变量 | 表面、文字、边框、强调、画布连线、状态 | 为两套主题提供相同名称 |
| 组件配方 | 按钮、输入框、侧栏、窗口标签、节点、时间线、弹窗 | 消费语义变量，统一尺寸与状态 |
| 页面 | 生成、画布、其他全局页面 | 组合组件，不自行决定主题色 |

## 与当前 CSS 的对应关系（只读检查）

当前 `App.css` 已把 `.film-window-tabs` 设为 48px，且在 Tauri 运行时隐藏示意用的三色圆点。窗口栏结构分别出现在 `App.tsx` 的恢复中／未打开项目状态，以及 `StudioWorkspace.tsx` 的项目工作区。还原设计时应由桌面壳统一承载这一栏，让三种状态共用同一位置和换肤入口。

`Studio.css` 有局部的 `--film-*` 变量，但生成页、节点、检查面板和弹窗中仍有大量直接写入的暖色色值。`App.css` 的根背景与文字也直接使用 C4 色值；`Editor.css` 则混用较早的 `--avs-*` 变量与蓝白色值。实施换肤时，先建立基础原子和语义变量，再让这些现有选择器消费组件配方；页面级布局选择器继续负责尺寸与排列。这样一次切换才能同时覆盖项目内外、生成、画布和旧编辑区域。

## 页面应用规则

- **生成页**：顶部窗口栏、左侧导航、生成/画布页签、输入区、结果卡与状态按钮在切换时一起换色。上传、生成、任务恢复的行为不变。
- **画布页**：背景、网格、节点头、节点正文、连接线、选中边框、时间线及导出按钮一起换色。人物节点、视频节点、逐节点运行顺序不变。
- **全局组件**：对话框、通知、空态、加载与错误状态都跟随主题；成功或失败不能只靠颜色表达，必须保留文字或图标。
- **对比与焦点**：正文与关键按钮保持可读对比；键盘焦点在两套背景上都清楚可见。减少动态效果设置应被尊重。

## 验收标准

1. 四张预览中窗口栏尺寸、控件位置一致，内容均从 48px 以下开始，页面没有裁切或重叠。
2. 在生成页与画布页均能看出两套外观的同一组件对应关系；图 1 的青蓝画布视觉被纳入全局方案。
3. 换肤入口只需一次操作；切换后同一项目的所有页面同步更新，输入、工作流与生成任务保持原状。
4. 应用代码实现时，页面颜色由主题变量与组件配方提供；新增页面不再手抄 C4 或青蓝色值。
5. 本次只交付 Pen 设计和此文档；代码还原等待用户审阅设计后进行。
