# 生成与画布逐节点工作流设计

## 目的

让创作者从参考照片和文字生成短视频，再把多个生成结果放进可自由搭建的画布工作流，整理为一集。画布还应能创建并复用人物，使连续镜头保持相同人物设定。桌面端的「生成」和「画布」采用用户提供的即梦截图所示的信息架构：生成页以输入区为中心，画布页以深色节点空间、左侧工具栏、节点连接和上下文配置为中心。界面使用 AI Video Studio 自己的名称、图标与素材。

## 已确认的方向

- 用户选择先做**逐节点运行**：创作者检查每个节点的输入，再手动启动该节点；画布首版不自动运行整张图。
- 画布能自行创建 workflow；人物、生成视频和整集编排属于同一条创作路径。
- **一张画布制作一集**；画布中的多个视频节点是这集的片段／镜头，经时间线编排成完整内容。一个本地项目可有多张集画布。
- **人物先用参考照片创建**：录入名称和文字设定，不在首版接入 AI 生成人物图或三视图。
- 生成的视频能够加入指定集的画布，再组合成完整内容。
- 原有本地项目、分镜／时间线编辑和可灵图生视频任务恢复能力需要继续可用。

## 参考界面所体现的交互

截图里的连接点旁「＋」能添加下游节点；菜单中「文本、视频、时间线、主体」是高亮项，「图片、音频、导演台」在该连接位置置灰。画布中已有图片节点，因此置灰只说明此处的添加条件，不能当作图片功能整体不可用。节点之间的线表示参考内容的传递，选中视频节点后出现提示词、参考素材与生成控制。截图没有证明整张画布支持一键运行，也没有证明连线会自动付费生成。

## 方案比较

1. **媒体编排画布**：只把已生成视频作为卡片加入画布，连接到时间线。实现快，但人物与生成步骤无法成为可执行 workflow，不符合用户希望自行搭建工作流的方向。
2. **逐节点执行图（用户已选）**：人物／参考素材／文本连接到视频节点，视频节点由用户逐个生成，成功结果接入时间线。能复用当前可灵任务恢复和本地导出；需要新增节点、边、有效性检查与持久化。
3. **整图自动执行**：一次点击依赖顺序运行所有节点。多次付费请求、部分失败续跑、输入变更后的失效传播和费用边界会显著扩大首版范围，留待后续。

## 第一版页面与节点

### 生成页

工作台提供「生成 / 画布」入口。生成页允许选择本地参考照片、输入动作与场景提示词、选择当前能力允许的 5 或 10 秒无声视频，然后明确点击生成。页面显示任务状态和结果卡，结果卡有「加入画布」动作：选择已有集画布，或显式创建新集画布；不自动创建无名项目或画布。现阶段只有可灵图生视频；不展示不存在的配音、口型、任意视频编辑能力。沿用已决定的本地单一 API Key 配置，不增加首版模型切换、服务商设置或费用估算面板。

### 画布页

一个本地项目可创建多张集画布，项目级人物与素材可以复用；每张画布有自己的节点图、时间线和导出目标。画布采用可缩放、可平移的深色节点空间；顶栏显示集名和保存状态，左侧为节点工具栏，连接点提供添加下游节点菜单。节点支持选中、拖动、改名、连接、断开、删除；删除节点时先说明对下游引用的影响。节点面板显示输入、状态、结果与当前可执行动作。保存后重开保留节点位置、连线、输入和结果引用。

首版节点：

| 节点 | 输入与作用 | 输出 |
| --- | --- | --- |
| 文本 | 剧情、镜头或生成说明 | 可连接的视频提示词 |
| 图片／参考素材 | 本地照片或已有项目图片 | 可连接的视频参考图 |
| 人物（主体） | 名称、文字设定、上传的参考照片；在项目内共享 | 可供同集或跨集视频节点引用的人物设定与主参考图 |
| 视频 | 可放入已有视频素材，或使用图片／人物、提示词和当前图生视频参数手动生成 | 已有视频，或任务状态及成功后的视频素材 |
| 时间线／整集 | 当前集画布的多个成功视频结果，用户确定顺序与裁剪 | 当前集的预览和本地 MP4 导出 |

音频、导演台、AI 生成人物三视图、全图自动运行不在这条首版可执行路径里。图片节点首版用于引用图片。

## 搭建与执行

1. 在生成页生成视频，或在选定的集画布上创建人物、文本、参考图片和视频节点。生成页的成功结果以「已有视频」节点加入选定集的画布，不会因此新建付费任务。
2. 通过端口连接：人物或图片可作为视频生成节点的**唯一主参考图**，文本可作为提示词输入；成功的视频节点可连接到时间线节点。视频生成节点不能同时接入人物主图与另一张图片作为两个主参考；要切换参考图，用户须明确替换输入。禁止无效类型连接和循环。连接本身不启动付费请求。边线表示引用关系，不规定视频片段的播放顺序。
3. 选中视频节点后显示最终引用的照片和提示词。缺少参考图、提示词、有效 API Key，或源文件缺失时说明原因并禁用运行。用户明确点击运行后，先保存提交意图，再调用已有可灵任务；显示排队、生成中、结果下载、失败和状态待确认。状态待确认时只查询原任务，不再自动提交。
4. 输入或连线改变后，旧视频结果仍保留为历史素材，并标记与当前输入不一致；再次生成必须由用户明确点击。下游时间线不会静默替换已经选定的视频版本。
5. 每张集画布有一个整集时间线，只接收该画布上已成功落盘的视频。用户在节点中明确排序、裁剪和预览；空间位置与连线创建顺序不决定片段顺序。沿用现有本地导出能力为当前集生成 MP4，导出文件名或路径可区分集。导出不自动触发上游生成。

## 数据与兼容

当前 `project.json` 只有平铺的 `assets`、`clips`、`shots` 和 `jobs`，没有人物、集、节点或边。实现时增加有版本的项目格式及旧项目迁移：项目级保存共享的人物、素材和生成任务；每集保存画布节点、边、布局、片段顺序、字幕、封面与导出信息。现有平铺的片段和字幕迁入一张明确命名的默认集画布，保留原有分镜草稿和任务记录；迁移不触发生成或导出。画布节点只保存项目内素材 ID、分镜／任务 ID 和布局信息，不复制密钥或媒体文件。旧项目首次打开仍能继续使用原有剪辑内容，迁移失败要明确报错，不覆盖原文件。

一张画布对应一集，多集属于同一个本地项目。人物节点以已有照片为主参考，不调用图片生成服务。视频节点的唯一主参考图规则是本轮设计决定，依据现有可灵图生视频只接受一张源图的能力；未来支持多图参考时再扩展端口类型。

## 约束与不做的事

- 现有可灵路径目前只覆盖 5／10 秒无声图生视频；不把说话、配音和口型同步当作可运行能力。
- 画布执行必须保留付费确认、提交意图持久化和断线后查询，避免重复付费提交。
- 本地项目路径、素材缺失状态和导出仍要能在桌面应用中实际验证。
- Pen 设计图覆盖生成页、空画布、已连接的典型工作流与视频节点状态；当前本机 Pen.app 无法启动且 Pencil MCP 不能连接，交付前需恢复该工具。

## 验收

1. 从生成页完成一次无声视频任务后，结果能加入画布；任务失败或未确认时不出现可用视频结果。
2. 能在第一集画布创建人物并把同一人物连接到两个视频节点；创建第二集画布后仍能引用同一人物。保存、关闭、重开后集、人物、引用和节点位置不丢失。
3. 连接不扣费；每次视频节点运行都由用户明确触发。断线／响应丢失后只能查原任务，不能自动再次 POST。
4. 两个已成功的视频节点能按指定顺序进入当前集时间线、裁剪、预览并导出一集；第二集有独立的时间线和导出文件，两集导出互不覆盖，文件能在本地打开。
5. 旧项目的素材、分镜、片段、字幕和任务记录迁移后仍可查看与编辑；缺失文件有明确状态，不会伪装为可运行输入。

## 留给实现者的决定

节点画布的具体 React 组件库、节点坐标与视口状态的编码方式、边线绘制方式、键盘快捷键，以及生成页与现有剪辑工作台的内部组件复用策略，由实现者在计划中定；不得改变上面的用户可见流程和付费边界。
