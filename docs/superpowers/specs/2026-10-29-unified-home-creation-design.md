# 首页统一创作入口设计

日期：2026-10-29。状态：用户已批准方向与流程，开发细节见 `docs/product/2026-10-29-unified-home-creation-prd.md`。适用：网页与桌面端首页；保留现有项目库、画布、单镜头生成与任务审批链路。

## 意图与现状证据

用户希望从同一个入口完成两条路径：没有想法时输入关键词，让 Agent 给出三个**同一镜头**的提示词方向；已有想法时直接输入提示词或完整剧本。选定内容后创建或打开项目，再选择直接生成一个镜头，或进画布逐镜头制作并在时间线拼接。首页不能再把“找灵感”和“创建项目”堆成上下两块。

现状：`ProjectHome` 把 `PromptIdeas` 放在首屏卡片里，同时另设“开始新项目”；`PromptIdeas` 的输入框限 200 字，“我已有提示词”在网页端有时只跳项目库；`POST /projects` 目前只保存名称和空分集。画布已支持文本、图片、视频节点、逐节点运行与时间线，但没有将完整剧本自动拆成镜头的能力。首页因此存在视觉拥挤、输入丢失和流程断点。

## 方案取舍

| 方案 | 取舍 |
| --- | --- |
| **一个输入框、两个明确动作** | 用户一次输入，选“让 Agent 给我 3 个方向”或“用我的内容开始”。结果进入同一个项目与创作方式选择步骤；无需先理解项目。用户已选择。 |
| 同一卡片切换“找灵感／我有想法” | 每次只显示一个动作，但要先切换模式，且切换时需解释输入如何保留。用户未选。 |
| 自动判断输入意图 | 表面少一个选择，但关键词和短提示词容易误判，可能意外调用文字模型；不采用。 |

## 首页布局

```text
首页 / 开始创作
┌──────────────────────────────────────────────────────────────┐
│ 你想拍什么？                                                │
│ [一句想法、关键词、镜头提示词，或粘贴完整剧本          ]    │
│ [让 Agent 给我 3 个方向]   [用我的内容开始]                  │
│ Agent 仅处理 1–200 字关键词；已有内容可写更长的剧本。        │
│ 对输入的不同处理由用户点击的动作决定。                      │
└──────────────────────────────────────────────────────────────┘
获取灵感后：在同一主区域显示三种单镜头方向、选中态和编辑区。
辅助区域：最近项目 / 全部项目。项目创建按钮不再作为首页第二块主表单。
```

主输入区占首页视觉中心；标题、辅助说明和最近项目压缩为次级信息。1280×720 下输入框与两个动作都在首屏。窄屏改为单列，两个动作保持完整文案。键盘焦点、错误提示、加载状态和请求恢复可见。

视觉沿用项目现有的胶片工作台：浅色使用背景 `#f7f2eb`、正文 `#2b2a26`、主操作 `#b96c4a`、表面 `#fffcf8`；深色直接使用现有主题变量。只让输入区成为醒目的大面，标题缩短为“你想拍什么？”，减少英文装饰标签和胶片装饰占首屏高度。最近项目以一行摘要或紧凑卡片呈现，不与主输入区争夺视觉层级。按钮文案使用明确动作，次按钮不冒充主按钮。

## 两条入口汇合后的流程

1. **无灵感**：输入 1–200 字关键词，点“让 Agent 给我 3 个方向”。沿用当前账号级草案、三版单镜头提示词、选择和编辑、同请求 ID 查询与限流；三版不自动创建项目或视频任务。点卡片只改变选中态，用户点“用这条灵感开始”才进入统一的“开始这个作品”步骤。
2. **有灵感**：输入 1–10000 字提示词或剧本，点“用我的内容开始”，直接进入同一步骤；不调用 Agent。超出长度、空白内容阻止继续并说明原因。切换路径不清空输入。
3. **开始这个作品**：展示原文/最终选定提示词、可编辑项目名、默认“新建项目”，并可选“加入已有项目”；用户明确提交项目归属。项目名可由内容前 20 个字符预填，但必须可改。创建失败或响应丢失时沿用同一项目 ID 查询原项目，避免重复建项目。
4. **选择制作方式**：在同一步骤里选“直接生成一个镜头”或“进入画布编排多个镜头”，选择结果随项目创建一起确认。默认不替用户提交付费视频任务。打开已有项目时同样把内容保存到该项目再跳转。
5. **直接生成**：把文本带到现有单镜头准备页，要求照片、分集和 5／10 秒时长；用户检查计划并再次确认后才调用视频服务。若文本是完整多镜头剧本，明确提示先挑出一个镜头或改走画布；不能截断剧本、把整篇剧本伪装成单镜头提示词。
6. **画布编排**：项目保存完整原文；首集画布放一个可编辑的“创作原文”文本入口，作为用户拆镜参考。用户自己建立/连接逐镜头节点，再分别启动视频任务，成功后加入时间线并导出。进入画布和建节点不扣视频额度。此版不承诺 Agent 自动拆镜。

## 保存与恢复

- 项目需要持久保存创作原文及来源（手写或 Agent 草案 ID、选中版本 ID）。原文是项目创作资料，区别于视频服务的单镜头提示词；从旧项目新增想法时追加一条创作资料，保留原记录。网页云项目由当前账号拥有，桌面本地项目保存在本机；已登录桌面沿用现有云关联状态，不用“已登录”冒充“已同步”。
- 新建项目与原文应作为一次可恢复的创建意图处理：同一 ID 重试不会新增第二个项目；创建成功后进入所选制作方式。若项目已创建但后续打开失败，显示原项目入口供恢复。
- 加入已有项目时不得覆盖旧剧本或画布。先呈现“作为新创作原文保存/进入目标分集”的选择；保存冲突需提示，不能静默合并。返回首页或切换页签时保留未提交的输入，账号切换后不显示前一账号草案。
- 文字模型凭证留在服务端；获取三版不占视频额度。只有用户确认生成计划时才进入视频任务审批。断线恢复继续查询原任务。

## 异常与空态

| 场景 | 用户看到 / 能做什么 |
| --- | --- |
| 无内容或超长 | 在输入框旁看到限制和修正动作；不创建项目或请求模型。 |
| 文字模型未配置、超时、限流 | 显示真实原因；可查询原请求或改用自己的内容，不能用模板假装 Agent 结果。 |
| 尚无项目 | 仍可先输入与获取灵感；项目选择步骤提供明确新建入口。 |
| 无参考照片 | 可保存项目与进画布；直接生成前提示上传照片。 |
| 创建项目响应丢失 | 使用原 ID 查询；状态未确认时不自动另起新项目。 |
| 离开再回来 | 未提交输入与已选灵感仍在；已创建项目内原文可找回。 |
| 桌面未登录 | 可用已有内容建本地项目；Agent 入口解释需要登录；项目仅在本机。 |

## 验收标准

1. 网页与桌面首页都只有一个主输入区，1280×720 首屏可见两个入口；不再出现上下并列的“灵感卡 + 建项目”主模块。
2. 关键词 → 三版 → 选/改一版 → 建/选项目 → 选直接或画布，全程文本不丢；已有内容不调用 Agent，直接进入同一项目步骤。
3. 新项目和已有项目均可找回创作原文；画布中的首集可看到原文并手动拆镜，且不会意外覆盖既有节点。
4. 直接生成只接受用户明确确认的单镜头提示词、照片与时长；多镜头剧本给出处理指引；任何入口都不会自动提交付费任务。
5. 覆盖空白/超长、模型失败、照片缺失、项目创建响应丢失、刷新与账号切换、桌面离线/未登录、项目保存冲突。验收记录区分网页浏览器实测、桌面原生实测和模拟服务测试。

## 此轮不做

Agent 自动拆分完整剧本、自动批量运行所有画布节点、整集一键生成、真实文字模型服务选型；这些需要单独的成本、可控性和失败恢复设计。
