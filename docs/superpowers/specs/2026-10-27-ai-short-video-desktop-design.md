# macOS AI 短视频创作工具：产品与技术设计

日期：2026-10-27

## 1. 目标与背景

从全新仓库独立开发一款可在面试中现场演示的 macOS 桌面应用。用户上传人物或宠物照片，输入故事与指定台词，应用生成短视频片段、同步口型的说话片段，并提供基本剪辑、字幕、封面、发布文案和导出。另一个入口允许用户导入已有视频做短视频剪辑。

首个演示故事：上传一张狗的照片，狗穿厨师服在厨房洗菜做饭，使用童声准确说出“妈妈要下班了，我在家做饭给她吃”，说话镜头中的狗嘴型与音频同步。用户同意在台词处切换为厨房内狗的正面镜头，其余镜头展示做饭动作。

项目代码独立实现，不复制妙码或 AutoClip 的受限代码。第三方模型以服务 API 的方式调用；最终开源许可证和依赖清单在发布前核对。

## 2. 已确认的产品决定

- 平台：第一版仅 macOS。
- 素材主体：人物和宠物均支持；不能以人物效果代替宠物验收。
- 成本：先满足核心效果，再优先选择低价模型。用户自配 API Key，按调用付费；应用不提供代充值或计费账户。
- 生成方案：低价云端组合为默认，Runway 作为可切换备选。应用保留模型适配层，不把业务流程写死在某家 API 中。
- 口型：明确要求说话镜头的嘴型跟指定台词同步；普通旁白不能替代。
- 创作流程：固定 AI 模板与自由提示词均可进入同一分镜与剪辑流程。

## 3. 首版范围

### 必须完成

1. 本地项目：创建、打开、保存和重新打开项目；源素材与生成片段按项目目录管理，不修改用户原始照片或视频。
2. 导入：单张人物或宠物照片、已有视频、音频；检查文件类型、可读性和时长。
3. 故事输入：提供“宠物小厨师”固定模板及自由提示词；允许编辑分镜、镜头提示词和需要逐字朗读的台词。
4. 参考画面：用原照片生成或选择镜头起始图；用户可以确认主体相似度后再进行付费视频生成。
5. 视频生成：逐镜头提交、显示排队和进度、保存原始结果；允许只重做一个镜头。
6. 配音与口型：先生成或导入音频，试听确认后制作人物或宠物说话镜头；台词保持用户确认的原文。
7. 基础剪辑：导入片段、排序、裁剪入出点、音量调节、添加或编辑字幕、选择封面帧、生成并编辑发布文案。
8. 导出：竖屏 9:16 MP4；导出前显示缺失素材或生成失败状态；在本地完成拼接、混音、字幕和封面导出。
9. 费用控制：发起付费任务前显示模型、预计时长与预计费用；支持每项目预算上限和本次任务明确确认；记录实际任务、模型与已知费用。
10. API Key：用户自己填写；保存在 macOS Keychain 或等效系统安全存储中，不写进项目文件、日志或开源仓库。

### 后续版本

- 多人物或多宠物同镜头、多语言配音、长视频时间线、高级转场、自动发往社交平台、云同步、团队账户、应用内充值。
- 本地部署大视频模型；首版仅本地剪辑与预览，视频生成使用远端 API。

### 不接受的结果

- 狗的说话镜头仅有旁白，嘴巴不跟台词动。
- 用另一个外貌明显不同的狗替代原照片主体。
- 自动重试导致用户不知道费用增加。
- 把源素材覆盖，或丢失已经成功生成的镜头。
- 宣称任意照片必然获得准确的爪部动作、完美的中文唇形或零次重试。

## 4. 路线比较与选择

| 路线 | 优点 | 缺点 | 结论 |
| --- | --- | --- | --- |
| Hedra 聚合 API：Seedance 1.5 Pro 无声图生视频 + Kling AI Avatar v2 音频驱动说话 | 同一 API 平台、较低公开单价；Kling 说明明确包含动物；可分别重做镜头 | 依赖平台、模型和价格会变；实际宠物口型与主体保持需试样 | 首版默认 |
| Runway Gen-4 Turbo 图生视频 + 动物口型模型 | 有成熟图生视频 API，可在默认画面效果不佳时切换 | 视频单价较高，还需第二家口型服务 | 备选 |
| 本地开源视频模型 | 无逐次视频 API 费，控制力高 | 算力、模型下载、推理、宠物口型均需额外投入 | 不进入首版 |

选择先以低成本实测，再按画面效果决定是否切换单个镜头的生成模型。固定模板可直接形成分镜，节省不必要的语言模型请求；自由故事才调用 DeepSeek 等语言模型做分镜和文案。语言模型不能替代图生视频或口型模型。

### 价格基线与规则

按 2026-10-27 查到的公开单价，Seedance 1.5 Pro 720p 无音频约 US$0.025/秒，Kling AI Avatar v2 标准档 720p 约 US$0.0562/秒。10 秒无声做饭镜头加 5 秒说话镜头，视频生成基线约 US$0.531；不含图片、配音、文字模型、税费和重做。Runway Gen-4 Turbo 约 US$0.05/秒，同样 10 秒做饭镜头加 Kling 5 秒说话镜头，视频生成基线约 US$0.781。价格必须由适配器配置或服务端元数据更新，界面写明是估算，不能硬编码为永久承诺。

## 5. 技术结构

- 桌面：Tauri 2 + React + TypeScript。原生层管理文件、任务和密钥；前端管理创作流程与剪辑界面。采用 Tauri 的原因是第一版仅 macOS，并希望控制应用体积。代价是 Rust 原生逻辑与 Web 前端需要清晰接口。
- 模型适配器：统一的图像、图生视频、配音、口型、文字生成接口。Hedra 为首个图生视频与口型平台；Runway 图生视频为备选。适配器记录模型版本、输入参数、请求标识、输出和价格元数据。
- 异步任务：提交后持久化任务 ID；轮询或回调获取状态；应用重启后可继续查看原任务，不重复付费提交未知状态的请求。重试必须显式创建新任务并再次显示估价。
- 本地媒体：FFmpeg/ffprobe 作为随应用打包的受控 sidecar，用于媒体探测、裁剪、混音、字幕与导出。仅允许应用生成的参数进入受控命令接口，不拼接用户输入的 shell 字符串。分发前核对具体二进制的 FFmpeg 许可证与署名义务。
- 数据：项目文件保存故事、镜头、编辑决策和任务元数据；照片、音频和视频存放在项目素材目录。生成片段按版本保留，导出结果与源素材分开。
- 安全：密钥由原生层读取，前端只获取已配置/未配置状态；上传人物或宠物素材前明确显示将发送给哪家服务。用户需对上传的人物照片拥有使用许可。

## 6. 关键用户流程

1. 新建本地项目，选择照片或导入视频。
2. 选择固定模板或输入自由故事；填写需准确朗读的台词。
3. 预览并编辑分镜：镜头时长、动作、正面说话镜头、画面比例。
4. 生成或选择参考画面，用户检查人物/宠物是否仍可辨认。
5. 试听童声或用户导入的配音；确定音频后才提交口型任务。
6. 查看所有镜头的估价与项目预算，逐镜头生成；有问题只重做相应镜头。
7. 在时间线排序、裁剪、加字幕、选封面，编辑发布文案。
8. 导出 MP4 与封面图片，并复制发布文案。

## 7. 演示验收

- 用一张真实狗照片和一张人物照片各完成一次从导入到 MP4 导出的流程。
- 狗案例：狗可辨认为原照片主体；做饭动作可理解；说话镜头正面可见嘴部运动，童声准确朗读给定中文台词，嘴部节奏与音频基本一致；字幕无错字。
- 用户可修改台词或镜头提示词，仅重做对应镜头；原成功结果仍保留。
- 关掉并重新打开应用后，项目与任务结果仍在；未知状态任务不会被自动重新提交。
- 离线时可打开已有项目、预览和剪辑已有素材；新的 AI 生成提示需要网络连接。
- 生成前能看到估价和预算剩余，导出本地已有素材不触发云端生成费用。

验收不以模型宣传页代替真实测试。实测应保留原输入、输出、模型版本、次数和账单，以便决定默认模型是否确实兼顾成本与效果。

## 8. 尚待验证与实施者可决策事项

- 技术验证：同一狗照片和同一中文音频分别测试 Kling AI Avatar v2 与更便宜的 Hedra Avatar；如低价模型达到验收要求，可将其切为默认。人物也单独测试。
- 配音：在中文 TTS 候选中选一个能稳定生成合适童声的服务；首版允许用户上传自己的音频，避免单一 TTS 的声音限制。不得默默替换用户已经确认的音频。
- 参考画面：先用最少步骤得到主体一致的厨师/厨房首帧，实际测试后决定采用哪家图像模型；图像模型也通过适配层接入。
- 服务可用性：动工前确认用户账户可开通、地区与支付方式可用，以及服务 API 的实际配额。
- 剪辑交互细节、项目文件格式、字幕样式和第一版免费模板数量可由实施者按上述验收目标确定，并在实现计划中写明。
