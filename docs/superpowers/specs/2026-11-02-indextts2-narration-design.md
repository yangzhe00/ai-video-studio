# 文字旁白与本地自定义音色设计（待审核）

日期：2026-11-02。范围：AI Video Studio 网页端与 macOS 桌面端。取代先前 Replicate IndexTTS2、豆包 TTS 2.0 首版方案。本设计仅处理配音；可灵视频生成和整集剪辑 v3 独立实施。

## 用户意图与已确认的决定

- 第一版：网页和桌面共用云端文字配音服务，首个在线实现为火山引擎豆包音频生成 `seed-audio-1.0`。本轮只生成**旁白**，暂不把该模型的音效、环境声、多角色对话或图片参考作为产品入口。
- 第二阶段：桌面端在本机安装并通过性能检查后开放 IndexTTS2 自定义音色。参考录音只留本机，生成的**配音成品**可同步云端，供网页和其他设备试听、预览与导出。此入口第一版要求已登录、项目已同步且当前联网；离线任务和延迟同步留待后续。
- 免费试用耗尽、试用到期或无法确认仍处于免费试用状态时，暂停在线生成，不自动转为付费调用。保留上传录音入口。产品不宣传“永久免费”。
- 生成结果统一成为项目 `voice` 素材，由用户选择加入镜头或分集配音轨，设置起点、音量和裁剪，再预览/导出。旁白不自动覆盖原声，也不保证与 3–5 秒镜头时长精确一致。

## 为什么首版可以选 Seed Audio，以及边界

官方接口 `POST https://openspeech.bytedance.com/api/v3/tts/create` 使用 `X-Api-Key`，请求体必须带 `model: seed-audio-1.0` 和 `text_prompt`，可以纯文本生成，支持 `speaker`、语速及音频输出格式；是**非流式** HTTP，返回 Base64 音频或有时效的 URL，并返回 `original_duration` 计费时长。接口适合试做影视配音；它是可生成完整声音场景的创作模型，不能据此承诺逐字准确朗读。上线前必须实测“指定文案是否完整、准确、无额外音效/对白”，不达标就回到专用 TTS 2.0 适配器，而不是默默发布错误旁白。

官方计费文档列出 Seed Audio 1.0 试用额度 60 分钟、有效期半年，需在控制台领取；额度、适用范围和有效期以账号控制台为准。开启正式版、试用到期或额度用尽后可能进入后付费，故不能只凭本系统的本地计数宣称“绝不会收费”。上线门禁是：运营核对账号只处于允许的试用模式；如供应商提供可验证的剩余试用量接口则在每次任务前核查，并对并发预留保守余量；无法可靠判定试用状态时关闭在线生成。不要配置自动转正式版/后付费，管理员保留全局停用开关。若供应商配置仍允许超额后付费，免费模式验收不通过。

## 方案比较

| 路线 | 用途 | 取舍 |
| --- | --- | --- |
| `seed-audio-1.0` 非流式音频生成 | 首版文字旁白；未来可扩展音效 | 有试用分钟数、适合创意音频，但必须验证朗读保真，按音频原始时长计量 |
| `seed-tts-2.0` HTTP 流式语音合成 | 严格朗读场景的备选 | 专用 TTS、按字符计量；接口、请求体、响应流与 Seed Audio 不同 |
| 本机 IndexTTS2 | 第二阶段桌面私有音色 | 参考录音留本机，但要安装较大权重并按设备实测速度；网页端不能直接使用访客本机运行时 |
| Replicate 托管 IndexTTS2 | 先前候选 | 需要把参考录音发送第三方，与本机隐私决定不符；本设计不接入 |

## 分层契约，支持后续换模型

前端只调用既有共享 API 契约 `@ai-video/api-contracts` 的旁白能力：列出可用音色、提交文本/音色/语速和稳定 `clientRequestId`、读取任务状态和最终 `voiceAssetId`。网页与桌面不持有供应商密钥，也不直接感知火山请求体。服务端选用配置中的在线适配器；本机 IndexTTS2 是桌面受控适配器，最终也产出同一类 `voice` 资产。

适配器入口统一为 `synthesize({ purpose: 'narration', text, voiceId, speed, requestId })`，返回经过校验的音频、MIME、时长、供应商请求 ID、模型版本与可得的用量。能力表明确 `narration`、`sound-design`、`reference-audio`、`streaming`，不支持的能力直接拒绝。免费额度/费用策略属于服务层，不藏在适配器里。请求/响应继续由 Zod 校验，旧 `voice` 资产和旧任务可读。

**可配置切换的边界**：只有两个模型使用相同鉴权、端点、参数和响应协议，才可能只换模型 ID 和 API Key。`seed-audio-1.0` 与 `seed-tts-2.0` 甚至同属火山，但一个非流式返回 JSON 音频、一个流式返回分块音频，计费单位也不同；切换需新增/启用对应适配器及费用映射。不同供应商更不能靠改名称和 Key 直接替换。抽象的价值是让页面与业务契约稳定，把改动局限在适配器、配置和供应商专项测试。

## 当前项目的改动面

- `apps/api/src/kling-tts.ts`、`tts.ts`、`tts-voices.ts`、`config.ts`、`server.ts`：保留可灵**视频**网关；旁白从可灵任务式 `submit/query/download` 改为供应商中立服务与 `VolcSeedAudioHttpAdapter`。火山接口一次请求完成，项目数据库仍维持内部 `pending/running/succeeded/failed/unknown` 状态，不能虚构可轮询的供应商 task ID。音频必须在发布资产前完成大小、MIME、真实时长与音质检查；临时 URL 及时转存，下载做 HTTPS 域名限制、防重定向越界。
- `packages/api-contracts/src/requests.ts`、`responses.ts`：保留现有在线提交入口和 `clientRequestId` 幂等；为音色/任务增添可选 `provider`、`model`、`capabilities` 和供应商中立 `usage`，旧可灵特有 `actualCost` 响应兼容读取。`original_duration` 是计费依据，不把估算时长写成实际金额。
- 数据库做追加迁移记录 provider/model、请求 ID、生成时长与免费额度门禁状态；旧进行中/未知可灵 TTS 任务先核查，不能按新适配器重复提交。
- `plugins/video-edit/src/web/TtsLibraryPanel.tsx`、`apps/web/src/App.tsx`、`apps/desktop/src/features/studio/StudioWorkspace.tsx`：显示已验证的音色、生成状态、试用剩余/不可验证状态和“额度耗尽暂停”；复用成功后的素材试听与时间线。前端不得把试用余额显示为准确值，除非能从供应商可靠读取。
- 第二阶段桌面 Tauri 受限桥接 IndexTTS2：固定运行时和模型版本/哈希、受控路径、模型与设备健康检查、取消和资源上限。参考录音不得上传、进入云项目 JSON、日志或遥测；生成前提示“参考录音留本机，成品会同步”。私有音色失败不自动转在线。

## 任务恢复与失败处理

服务端先持久化请求意图，再向火山发送；同一 `clientRequestId` 重放只返回既有任务。超时、连接中断或响应不完整时，结果为 `unknown`，不得自动再请求，也不得自动换供应商，以免重复消耗试用量或计费。若官方没有可用的同请求查询接口，只能人工/账单核查后定论。半成品音频不能成为资产；旧成功资产始终保留。免费门禁失败时不进入供应商调用。

## 实施与验收门禁

1. 控制台核对 Seed Audio 1.0 试用已领取、账号计费模式、可用 Key/音色、余量和服务器连通性。用隔离项目做一次**有计量风险的最小请求**，核实返回格式、计费时长、账单及试用量变化；未核实前不宣称已接通。
2. 用 3–5 秒镜头文案、不同标点和人物名验证朗读文字一致性、无额外声响/对白、音色稳定、语速、首尾完整与生成时长；未过门槛则选择专用 TTS 2.0 适配器。试用额度耗尽/到期/不可查、并发临界、未知提交和断网均须阻止重复或付费调用。
3. 网页与桌面回归：文本 → 生成 → `voice` 资产 → 放入配音轨 → 预览 → 整集导出；核对旧上传录音、旧生成音频、跨账号隔离和幂等。第二阶段再做本地参考录音隐私、设备性能及成品跨设备同步验收。

## 旁白保真验收线（架构师提案，待用户审核）

首版上线前使用至少 30 条真实中文旁白样本：10 条普通短句、10 条人物名/数字/中英混读、10 条停顿/情绪表达；覆盖所有开放的内置音色。QA 双人听辨并保存音频与逐字核对表。以去除标点后的原文为准，任一漏字、添字、人物名误读、非请求的对白或音效均判失败，同时记录语速、首尾、音色稳定性和实际时长。由产品负责人签收。如有保真失败，Seed Audio 不作为首版旁白上线；改用专用 TTS 2.0 适配器并重新验收。这是实施判定标准，并非对 Seed Audio 现有效果的断言。
