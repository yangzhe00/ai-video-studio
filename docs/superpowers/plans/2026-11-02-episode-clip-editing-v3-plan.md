# 整集剪辑 v3：分片段编辑开发分工

日期：2026-11-02。依据：`docs/product/2026-11-02-episode-clip-editing-v3.md`、`design/prototypes/episode-clip-editor-v3/index.html`、`docs/acceptance/2026-11-02-episode-clip-editing-v3-test-scope.md`。

1. **架构/后端先定契约**：审视 `orderSavedVisuals` 等长排列约束、`timelineClips[].volume` 和全局 `audio.originalVolume`、真实渲染流程；设计可迁移的每段镜头原声模型、分割/合拢的视觉片段模型与旧数据投影。明确命令幂等、版本冲突、锚点受影响策略和存储版本。用三镜头及已混音旧镜头固定样本。
2. **后端实现读写与渲染**：允许新增、分割、删除视觉片段及重复引用同一视频素材，合法化源入/出点与稳定 ID；支持原声区间分割、静音、单段音量与删除；预览/导出音频与即时试听一致。旧项目读取、费用/生成资产、音频锚点不能退化。
3. **前端共享组件实现**：四轨可选、统一工具栏、分割/删除影响确认、画面拖边/排序、原声分段/单独音量、配音/音乐同样分割、键盘/撤销/保存失败与冲突。与正在并行开发的 v2 时间尺、AI 编辑、TTS UI 合并，不重置它们的修改。先实现可运行的本地纯规则，再接后端真实保存。
4. **集成与代码审查**：前后端给出同一候选提交或源码 SHA，运行受影响包测试与构建；审查原片保留、无隐式移轨/截断、视频和音频时间映射、旧数据和同账号多端冲突。不要把 CSS 演示当完成。
5. **测试独立验收**：测试会话按 C01–C09 在 Web 和 macOS 原生跑 15 秒与 12.3 秒场景，交截图、实际 MP4/ffprobe 和音频区间分析。失败修复后冻结新候选复测；最终直接向用户报告结果与截图。
