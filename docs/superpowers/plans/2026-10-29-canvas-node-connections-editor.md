# 画布连线与就地编辑修复

## 目标

在网页端和桌面端的同一画布插件中，人物/图片/文本可接视频，视频可在生成前接时间线。用户可点击端口两次，或从输出端口拖到目标节点完成连线。选中节点后，编辑框贴近该节点并保持正常字号；画布平移、缩放和窗口变化时仍贴近节点。

## 实施

1. 调整项目规则与网页端云画布规则，让视频到时间线的边可以先保存，实际加入片段仍须生成结果。
2. 给画布输出端口增加拖拽线和命中目标节点的交互；点击连线及键盘点击继续可用，非法方向仍由项目规则拒绝。
3. 根据节点在视口中的坐标定位不随画布缩放的编辑浮层，并在窗口边界内自动改为左侧或上移。
4. 测试项目规则和 UI 点击/拖拽回调，构建网页端与桌面端；在真实浏览器查看连线及编辑浮层的位置。

## 验收点

- 图片或人物、文本分别能连到视频；视频能在未生成时连到时间线。
- 重复连接、第二张主参考图和错误方向仍被拒绝。
- 拖动输出点时看到预览线；松到目标节点建立连接，松到空白处不产生边。
- 选中不同节点时编辑框跟随各自位置，且不超出画布可见边界。
