# Web H5 响应式改造方案

日期：2026-10-30。状态：已实现并完成浏览器视口校验。范围：`apps/web` 的登录、首页、创作、项目库、准备镜头、结果、资产、视频微调和画布入口。保留现有 C4 视觉与桌面交互。

## 当前问题

- `web-studio` 固定 `100vh` 且设有 `min-height: 680px`；短屏手机容易裁掉底部内容。
- 共用 `StudioShell` 在窄屏只把侧栏缩为 64px，手机可用内容过窄；账号和换肤入口也不适合触屏。
- 生成页的照片区、提示词、底部参数和最近内容按桌面宽度排列；项目、结果与弹窗需要针对手机重排。
- 画布为桌面式无限画布；手机 H5 不承载节点编辑，但需要保留明确入口和继续创作路径。

## 布局规则

| 宽度 | 导航 | 内容 |
| --- | --- | --- |
| `> 830px` | 236px 左侧栏 | 沿用现有双栏/多栏布局。 |
| `641–830px` | 64px 图标侧栏 | 主内容单栏，画布可平移缩放。 |
| `≤ 640px` | 顶部品牌栏、底部五项导航、账号抽屉 | 单栏内容；画布显示说明与“去创作/看结果”入口。 |

`641–740px` 的生成页另外把“最近创作”改成单列卡片，快捷入口保留局部横向滚动，避免 641px 断点处的三列内容挤压。

主容器使用 `100dvh`，并保留 `100vh` 回退；移动底部导航加 `env(safe-area-inset-bottom)`，内容不被系统手势区遮住。宽度使用 `min()`、`clamp()` 和可收缩的 `minmax(0, 1fr)`；以媒体查询切换结构，不靠整体缩放。少量标题在 `clamp()` 中使用 `vw`，避免无上下限的视口字号。手机触控目标至少约 44px。登录页按单栏排布，动画遵守 `prefers-reduced-motion`。

## 实际实现

1. `packages/components/src/StudioChrome.tsx`：Web 在 `≤640px` 增加顶部栏、底部导航和账号/项目抽屉；桌面宿主不启用。菜单关闭时从辅助技术导航树隐藏侧栏。
2. `packages/components/src/styles.css`：共享壳、首页、结果页的手机布局与安全区；保留桌面样式。
3. `packages/ui-web/src/studio.css`：生成页的照片、提示词、参数、按钮和最近内容重排；短屏页面内部滚动。
4. `packages/ui-web/src/WorkSetup.tsx`：手机端隐藏节点画布制作选项，并解释可在平板或电脑继续。
5. `apps/web/src/App.tsx`：通过 `matchMedia` 响应窗口变化；手机访问画布时渲染分集概览，不挂载无限节点画布。
6. `apps/web/src/styles.css`、`apps/web/index.html`：Web 专属页面、弹窗、视频微调与登录页适配；加入 `viewport-fit=cover`。
7. 添加导航和手机画布入口行为测试；运行受影响包测试、Web/桌面构建和依赖边界检查。

## 验收矩阵

实际浏览器检查 `320×568`、`375×667`、`390×844`、`412×915`、`640×800`、`641×900`、`768×1024`、`1440×900`。覆盖登录、首页、创作、项目库、结果、资产、画布入口和弹窗的代表状态；检查横向溢出、底部遮挡、导航可点、短屏滚动、双主题及断点边界。视频微调还需用真实生成素材做手机触屏验收。截图与测试结果见 `.codex/.agent/web-h5-test-report.md`。
