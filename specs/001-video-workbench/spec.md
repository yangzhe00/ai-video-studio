# Feature Specification: 视频成片工作台一期（Web）

**Feature Branch**: `001-video-workbench`

**Created**: 2026-11-11

**Status**: Draft → 待确认

**Input**: `docs/product/03-PRD.md`（17 条功能需求）+ `docs/product/04-交互定义.md`（端型矩阵/IA/任务流）+ 会话澄清记录（见 Assumptions）

## User Scenarios & Testing

### User Story 1 — 登录与数据隔离 (Priority: P1)

未登录用户访问任意功能页跳转登录页；输入手机号获取验证码（演示模式返回 Mock 固定验证码并明确提示），登录后仅可见本人数据。

**Why this priority**: 所有功能的前置门；无隔离则演示中数据混乱。

**Independent Test**: 未登录访问 /home 被拦截；两个账号互不可见对方任务/素材/成片。

**Acceptance Scenarios**:

1. **Given** 未登录, **When** 访问任意功能页, **Then** 跳登录页且登录后回到原页面
2. **Given** 已登录, **When** 请求他人任务数据, **Then** 服务端返回无权限（前端不可绕过）
3. **Given** 验证码错误/过期, **When** 提交登录, **Then** 明确提示并可重发（60s 防刷间隔）

### User Story 2 — 选题与讲稿（A 域） (Priority: P1)

输入领域/关键词 → 生成 5 条选题（标题+内容角度）→ 选定选题生成口播讲稿（分段，可逐段编辑）→ 一键生成分镜提示词 → 保存草稿可恢复。

**Why this priority**: 直击核心痛点"不知道做什么"，是黄金任务流起点。

**Independent Test**: 输入"居家收纳"能拿到 5 条选题；讲稿编辑后刷新不丢失；LLM 不可用时提示可重试并允许手写讲稿直进 B 域。

**Acceptance Scenarios**:

1. **Given** 已登录且 LLM 可用, **When** 输入关键词点生成, **Then** 30 秒内返回 5 条选题，防重复点击
2. **Given** 讲稿已分段, **When** 点击生成提示词, **Then** 每段至少 1 条提示词且可编辑
3. **Given** 编辑中离开页面, **When** 内容未保存, **Then** 弹确认提示防丢失

### User Story 3 — 素材与生视频（B 域） (Priority: P1)

素材库支持批量上传（jpg/png/webp ≤20MB）与站内 AI 生图；逐段关联「图片+提示词」提交生视频任务（可灵 Provider）；片段可预览/删除/重新生成（保留原参数）。

**Why this priority**: 核心生产环节，视频片段是合成的必要输入。

**Independent Test**: 上传 5 张图 → 关联提示词提交 → 任务中心出现排队→生成中→成功 → 预览片段可用。

**Acceptance Scenarios**:

1. **Given** 额度充足, **When** 提交生视频任务, **Then** 先执行额度预检，通过后任务入队
2. **Given** 额度不足, **When** 点提交, **Then** 按钮禁用/拦截并显示余额
3. **Given** 生图 API 失败, **When** 重试, **Then** 分类提示（参数/额度/供应商/审核/超时）且可改用本地上传兜底
4. **Given** 片段生成成功, **When** 重新生成, **Then** 创建新任务不影响旧结果

### User Story 4 — 模板合成与配音字幕（C 域） (Priority: P1)

选模板（内置「简约生活风」，后端预置无编辑界面）→ 讲稿分段 TTS 配音（火山引擎 Provider，音色可选，试听确认）→ 按配音生成句级字幕（可改字）→ 要素齐全后提交 ffmpeg 服务端合成 9:16 mp4。

**Why this priority**: 从片段到成片的关键转化，黄金任务流的交付环节。

**Independent Test**: 5 片段+配音+模板提交合成 → 任务成功 → 成片入库且声画对齐。

**Acceptance Scenarios**:

1. **Given** 缺少片段或配音, **When** 点提交合成, **Then** 禁止提交并逐项列出缺什么
2. **Given** TTS 失败, **When** 重试, **Then** 可重试且不影响已生成段落
3. **Given** 合成任务失败, **When** 重试, **Then** 保留全部要素仅重跑合成

### User Story 5 — 成片导出与版本（D 域） (Priority: P2)

成片在线预览、下载 mp4（文件名含选题标题+日期）；同一选题多次合成保留最近 10 版，可对比可删除。

**Why this priority**: 价值终点但逻辑简单，依赖 US4。

**Independent Test**: 合成成功后可预览可下载；重复合成产生版本记录。

**Acceptance Scenarios**:

1. **Given** 成片已入库, **When** 点击下载, **Then** 得到 `选题标题_YYYYMMDD.mp4`
2. **Given** 同选题已合成 10 版, **When** 再合成, **Then** 保留最近 10 版并提示清理

### User Story 6 — 任务中心与失败兜底（E 域） (Priority: P2)

全站异步任务（生图/生视频/TTS/合成）统一看板：状态机一致（草稿→已提交→排队中→生成中→成功/失败；失败可重试→已提交；成功→已使用→已合成→已导出；草稿→已作废）、按类型/状态筛选、失败分类展示、审核不通过不自动重试、参数错误需修改后才可重试、批量重试、可从任务跳回对应页面继续创作。

**Why this priority**: 长时任务不阻塞页面的支撑设施，演示健壮性的关键。

**Independent Test**: 强制 Mock 失败 → 任务中心可见失败分类标签 → 修改参数后重试成功。

**Acceptance Scenarios**:

1. **Given** 任务生成中, **When** 用户离开页面再回来, **Then** 任务中心可见最新状态
2. **Given** 失败原因为审核不通过, **When** 查看任务, **Then** 无自动重试且有明确提示
3. **Given** 失败原因为参数错误, **When** 点重试, **Then** 禁用并引导先修改参数

### User Story 7 — 用量与额度（E 域） (Priority: P3)

每用户独立额度账本：按任务记录消耗明细；额度低于 20% 预警；提交前预检拦截。

**Why this priority**: 不阻断主流程，但演示"成本可追踪"卖点。

**Independent Test**: Mock 供应商返回固定消耗值 → 用量页可见每任务消耗与余额。

**Acceptance Scenarios**:

1. **Given** 额度余额 25%, **When** 查看用量页/提交任务, **Then** 显示预警
2. **Given** 余额不足, **When** 提交任务, **Then** 拦截并显示所需/剩余额度

## Edge Cases（PRD 异常八项全覆盖）

- 网络中断：上传断点提示、任务中心可手动刷新状态
- 供应商故障：分类提示+排队重试；可灵为一期唯一供应商，故障时明确提示"稍后重试"（多供应商切换为 Provider 抽象预留，不实现）
- 并发/重复提交：按钮防重 + 任务幂等（同参数任务去重）
- 数据丢失：编辑离开提示、版本历史兜底
- 长时等待：进度展示，页面可离开
- 空状态：素材库/草稿/任务中心空态引导
- LLM 不可用：手写讲稿直进 B 域
- TTS 不可用：明确提示（一期无自录兜底）

## Requirements

### Functional Requirements（映射 PRD FR 编号）

- **FR-001**(E-04): 手机号+验证码登录，演示模式 Mock 验证码；会话过期跳登录并保留当前页
- **FR-002**(A-01): 关键词生成 5 条选题，防重复点击，失败可重试
- **FR-003**(A-02): 讲稿分段生成与逐段编辑，重生成需确认
- **FR-004**(A-03): 段落→分镜提示词，可编辑，带入生视频
- **FR-005**(A-04): 选题/讲稿草稿保存、恢复、删除
- **FR-006**(B-01): 站内 AI 生图（Provider 抽象，Mock 默认），入素材库标注来源
- **FR-007**(B-02): 批量上传 jpg/png/webp ≤20MB，格式拦截提示
- **FR-008**(B-03): 图+提示词关联，提交生视频（可灵 Provider），额度预检
- **FR-009**(B-04): 片段预览/删除/重新生成（保留原参数）
- **FR-010**(C-01): 内置模板选择（后端预置），合成前必选，预览可见
- **FR-011**(C-02): 分段 TTS 配音（火山引擎 Provider），音色可选，试听确认
- **FR-012**(C-03): 句级自动字幕，可手动改字
- **FR-013**(C-04): ffmpeg 服务端合成 9:16 mp4，要素缺失禁提交并列清单
- **FR-014**(D-01): 成片预览与下载（文件名含标题+日期）
- **FR-015**(D-02): 版本历史保留最近 10 版
- **FR-016**(E-01): 任务中心统一看板，状态机一致，筛选
- **FR-017**(E-02): 失败分类与重试规则（审核不通过不自动重试；参数错误先改后试）
- **FR-018**(E-03): 用户独立额度账本、20% 预警、提交预检

### Key Entities

- **User**: 手机号、额度余额；独立于角色权限（一期无角色）
- **Topic（选题）/Script（讲稿）/Segment（讲稿段落）**: 段落与分镜一一对应
- **Asset（素材）**: 图片，来源=上传/生图
- **GenerationTask（生成任务）**: 类型=生图/生视频/TTS/合成；状态机见 FR-016；供应商、消耗、失败分类
- **Clip（片段）**: 单条生视频结果，关联段落与素材
- **Template（模板）**: 后端预置（片头/片尾/字幕样式/BGM）
- **Composition（合成）**: 片段集合+配音+字幕+模板→成片；版本历史
- **FinalVideo（成片）**: mp4，文件名含选题+日期
- **QuotaLedger（额度账本）**: 每任务消耗明细行

## Success Criteria

- **SC-001**: 黄金任务流（登录→选题→讲稿→提示词→素材→生视频→合成→下载）全程可演示跑通，Mock 模式下无真实 API 依赖
- **SC-002**: 全部异步任务状态流转与 PRD 状态机一致，失败分类可见
- **SC-003**: 演示模式下双账号数据完全隔离（服务端强制）
- **SC-004**: 7 个一级页面 1366×768 / 1440×900 / 1920×1080 三档分辨率可用

## Assumptions

- **端型（已确认）**: 一期 Web-only，`packages/*` 保持平台无关可移植
- **供应商（已确认）**: 可灵（唯一视频生成）、火山引擎 TTS、ffmpeg 合成、本地磁盘存储（StorageProvider 抽象预留 S3/OSS）
- **额度（已确认）**: 每用户独立额度；项目用途为面试演示
- **登录（已确认）**: 手机号+验证码；演示用 Mock 验证码；真实短信供应商预留（腾讯云/阿里云约 0.045~0.05 元/条，需签名报备审核）
- **讲稿时长（待复核）**: "5-10 秒"按**每段**理解（5 段 × 5~10s ≈ 25-50s 成片）；若指全片总时长需回改本文档
- **数值默认值（可配置，非硬编码）**: 选题 5 条/次、超时生视频 15min/合成 30min、额度预警 20%、素材 20MB、版本 10 版
- **内容审核**: 依赖可灵供应商侧审核结果，不自建
