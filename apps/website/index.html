05 / GOOD TO KNOW

常见问题。

开始创作和安装之前，你可能还想知道这些。

需要先有照片吗？＋

写下想法和建立项目时不需要照片。要使用参考照片生成视频时，再添加照片并确认镜头计划。

Agent 三版镜头方向什么时候可用？＋

目前即将开放。现在请在网页版使用“用我的内容开始”路径。开放后，它提供的仍是可编辑文字提案，不会直接生成视频；视频生成需要再次确认。

完整剧本能自动拆成多个镜头吗？＋

当前不会自动拆镜。完整剧本会作为创作原文保存在项目里；进入分集画布后，可手动建立和编排镜头。

桌面项目会自动出现在网页版吗？＋

不会。桌面本地项目需登录并关联云端后，才可在网页版找到；未登录的本地项目不会自动同步。

为什么 macOS 提示无法验证开发者？＋

当前提供的是未经 Apple 公证的测试版。首次打开时可能遇到系统拦截，请阅读 Apple 官方说明并按系统界面操作。
